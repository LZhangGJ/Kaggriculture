# 遗传路线库扩展与最强 agent 接入实验（2026-08-26）

## 目标与结论

目标不是寻找一条固定的 counter 路线，而是从现有高分 replay 路线出发生成新的可执行
路线，扩充路线库，并让当前最强 agent 根据实际市场轨迹选择是否使用它们。

实验完成了从 175 到 183 条路线的扩展。最终控制器保留 G001 开局、144/168/216
三个在线检查点和“最多切换一次”的原有结构；新路线只以经过验证的残差分支进入旧树。
推广后的单文件 SHA-256 为
`24b4a3137742f75de881a05355ee09839e237ef9761dd90af3b8736eff7770d7`。

## 方法

1. 以当前策略的 11 个目标族为多父本，而不是只变异 G001。
2. 对市场动作的时间、数量和阶段组合执行遗传变异；每个父本保留独立精英，避免全局
   排名把弱但互补的路线族清空。
3. 适应度定义为候选对当前 11 路线组合的边际 oracle 覆盖，轨迹由真实市场随机种子、
   双座位和 144/168/216 状态产生。
4. 在完全未见的 seed 和全部 175 个原路线对手上去重并贪心选择互补候选。
5. 把入选路线物化为完整动作带，并做 183 路线循环赛和执行失败审计。
6. 直接重训的 19 目标树在留出上低于旧策略，因此没有替换旧控制器。
7. 改用保守残差策略改进：在旧树每个叶内，以成对反事实结果提出 EV 覆盖；候选必须
   同时通过按 seed 和按对手分组的单侧 95% 下界，再在完整“首次切换即锁定”序列中
   贪心验证。未获证据的状态保持旧策略。

这个流程将“不退化”写入了路线生成后的接入方法，并且没有使用 opponent ID、队名或
固定市场轨迹作为线上特征。

## 路线生成结果

- 训练搜索：11 个父本、173 个候选；32 个代表对手、8 个 seed、双座位、3 个检查点。
- 独立筛选：全部 175 个旧路线对手、16 个新 seed、双座位。
- 旧 11 目标 oracle 得分率：93.5923%。
- 加入 8 个互补候选后的 oracle 得分率：94.3542%。
- 183 路循环赛：16 个新 seed、532,896 局；EV001 固定路线排名第 5。

8 个物化路线来自 G001、G006、G169、G008 和 G227 五个父族。最终线上真正使用两条：

- `EV001`（父本 G001）：144–288 增加小麦成品和甜瓜种子购买，288–432 减少羊毛
  出售，576–719 小幅减少小麦出售。
- `EV003`（父本 G006）：0–144 减少肥料出售，144–288 减少小麦成品购买。

## 轨迹切换与消融

19 目标反事实标注使用 seed 1000–1063、183 个对手、双座位和三个检查点，共
1,335,168 局、70,272 个状态向量、147 个特征。EV 路线成为最优标签的比例在
144/168/216 回合分别为 37.47%、47.29% 和 33.56%。

直接重训树在 seed 1128–1255 的留出得分率为 88.40%，低于旧线上树的 89.59%，因此
被拒绝。残差候选在 seed 1064–1127 的完整序列选择中由 88.56% 提升到 89.80%，最终
保留：

- 168 回合：旧 G006 叶的一条 `EV003` 覆盖；
- 216 回合：两个旧 G001 叶的 `EV001` 覆盖。

在 seed 1128–1255 的独立原生留出上，残差策略为 90.625%，旧线上策略为
89.5919%，提升 1.0331 个百分点。
