# 生成式动物路线实验（2026-08-26）

## 结论

生成器已经从纯作物扩展到完整动物生产链。最佳新基因
`GRG1-88fc93c5bff558c3` 不复用 replay 动作，在 seed 17 筛选中得到 49,440；在
seeds 17/29/43/71、双座位的八场增量验证中平均 44,860.125、最低 36,651，组合
稳健适应度为 42,446.18125。

对照的 3 COW + 3 SHEEP 结构先验八场平均 40,286.5、最低 38,385、稳健适应度
39,458.9875。增加第七只羊提高了平均收益和组合稳健适应度，但降低了最差场收益，
因此它是当前均值/风险目标下的精英，不是无条件支配基线。

## 新的策略表达

`GenerativeRouteGenome` v2 增加：

- 三阶段 GOOSE/COW/SHEEP 累计容量；
- 可搜索的饲料缓冲天数；
- 作物与动物共享的土地、劳力、资本和布局容量约束；
- v1 零动物 checkpoint 向后兼容，且保持原行为哈希。

状态控制器新增 BUILD_COOP、BUILD_PASTURE、BUY_ANIMAL、PICKUP、PLACE、
BUY_PRODUCT WHEAT、FEED、CARE、HARVEST、COLLECT_FERTILIZER 和动物产物/肥料出售。
动物变异、动物类型迁移、饲料缓冲和动物字段交叉也进入自适应算子池。

## 关键诊断

第一版动物控制器在小型 3 COW + 3 SHEEP 先验上得到 30,069，但高分 replay 宏观
初代出现“牧场已建、动物已领取、最终 0 放置”。原因不是资源不足，而是 50 个作物
目标持续产生更高优先级任务，携带动物的工人也被重新派去浇水和收获。

修正采用通用资源承诺：一旦某个 actor 携带 PLACE/FEED 所需专用资源，只从匹配该
资源的任务中选目标，完成交付后才回到普通任务池。它不是针对某个 replay 的例外规则。
同一批策略重放后：

- 3 COW + 3 SHEEP 先验：30,069 → 40,869；
- 最佳公开 replay 宏观初代：11,293 → 33,894；
- 该 replay 初代实际放置全部 15 只目标动物。

## 进化结果

将公开 replay 动物档案、两个动物结构先验和上一轮最佳作物精英合并，统一按控制器
版本、seed 和座位签名重新评估。两代 20 个混合候选中，`animal_capacity` 把结构先验
的 SHEEP 容量从 `0/1/3` 改为 `1/2/4`，形成：

- 阶段日：0 / 5 / 13；
- 作物终局：WHEAT 10、CARROT 1；
- 动物终局：COW 3、SHEEP 4；
- 劳力：2 / 5 / 8；
- 饲料缓冲：2 天；
- 全部 18 个目标位于 NW，不买土地。

seed 17 中实际完成 7 次建造/放置、134 次喂养、132 次照料、120 次肥料收集，最低
现金 1,385，最终现金 49,440。相对 40,869 结构先验提升 20.97%。

随后又运行两轮局部开发，共 24 个候选。动物容量、动物类型、阶段、劳力、布局、资本、
购种前视和饲料缓冲均获得试验机会；最近候选为 `layout + animal_capacity` 的 47,754.5，
没有刷新全局最好，当前邻域可以暂时停止。

八场仍是小面板，而且对手只是 `starter_agent`。这些数值用于验证生成和局部比较，不能
外推为榜单分数。

## 下一步实验

1. 用真实高分路线/agent 组成小型对手面板，重新评估市场竞争下的动物组合。
2. 将每日贪心任务分配升级为按工作区保留 actor 的分配器，减少当前每局数千次移动。
3. 搜索是否保留并使用肥料，而不是全部出售；这需要在基因中加入施肥目标和资本回报期。
4. 对入围路线使用至少 16 个新 seed、双座位 holdout；风险目标同时报告均值、5% 分位
   和 paired regret，而不是只优化单种子奖励。
