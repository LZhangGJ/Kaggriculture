# 完全生成式路线实验（2026-08-26）

## 结论

实验已经从“高分 replay 动作带加差分补丁”切换为“宏观基因生成策略、官方模拟反馈、
自适应生成下一代”的闭环。最终候选 `GRG1-f7609f5b8d4ce762` 的 719 回合动作全部由
当前状态生成，不读取任何 replay 动作；单种子筛选奖励为 29,151，在 2 个独立种子、
双座位的四场晋级面板上平均 28,952.25、最低 26,991。

这证明现在可以生成并改进公开 replay 中不存在的新路线。它还不是比赛最终策略：当前
生成控制器只覆盖作物，分数仍明显低于包含动物、肥料和成熟市场调度的公开高分路线。

## 方法变化

旧的 `route_compiler.py` 保留为重建和诊断基线。它适合回答“某个计划改动为何执行
失败”，不再承担新路线生成。

新的执行与搜索分为三层：

1. `GenerativeRouteGenome` 保存三阶段累计作物规模、阶段日期、劳力、扩张许可、资本
   储备、销售储备、布局种子和购种前视期。
2. `GenerativeRouteAgent` 从每回合观察构建任务，自动完成购种、雇工、移动、除草、
   播种、浇水、收获、出售和按需买地。
3. `MAPElitesArchive` 保存不同生产生态位的精英；自适应算子池按真实父子收益更新
   `crop_capacity`、`crop_mix`、`phase_timing`、`labour`、`layout`、`capital` 等生成概率。

公开 replay 只通过 168/288/432/576/719 等宏观布局锚点初始化基因。转换过程不读取
逐回合动作，也不把 replay 中的市场价格环境写入遗传身份。

## 实验轨迹

所有筛选局使用官方本地 `kaggriculture` 环境。便宜筛选为 seed 17、座位 0、对手
`starter_agent`；晋级验证使用 seeds 17/29 和双座位。

| 阶段 | 最佳奖励/均值 | 发现与处理 |
|---|---:|---|
| 第一版状态控制器 | 120 | 把一次性作物的初始 `yield_units=1` 错当成熟，重复无效收获且不浇水 |
| 统一成熟度模型 | 2,895 | 种植—浇水—收获—出售闭环跑通，但无条件买三块空地 |
| 按目标需求扩张 | 24,023 | “到日必买”改为“最早允许日且确有跨地目标才买” |
| 单步自适应搜索 | 25,808 | `crop_capacity` 生成新高价值组合；四场验证均值 25,991.5、最低 25,537 |
| 复合变异搜索 | 29,151 | `phase_timing + labour` 将中期从第 6 天提前到第 2 天，并把中期工人 5→3 |
| 复合精英晋级验证 | 28,952.25 | 四场最低 26,991，平均对 starter 优势 25,398.25 |

四个合成结构先验在修正扩张语义后的奖励分别为：

- 快周转 WHEAT/CARROT：10,040；
- 持续作物 TOMATO 主导：11,450；
- 高价值 MELON/STRAWBERRY 混合：24,023；
- 小田控制：8,377。

这说明当前移动模型下，高价值、低重播频率作物明显优于大规模一次性快周转。

## Replay 初代结果

从 6,026 个聚合 RouteGenome v2 中按公开 replay 奖励取前 8 个宏观初代，与 4 个合成
初代一起执行。8 个 replay 初代中的最好奖励为 20,557，低于合成高价值先验，但增加了
大田、多地块生态位。合并档案后搜索保留这些结构作为交叉素材；它们没有被简单按总分
淘汰。

当前 replay 初代落后的主要原因不是 replay 本身差，而是 v1 转换只继承作物锚点，忽略
了这些高分路线中大量 COW/SHEEP、肥料和相应市场收益。因此这组结果只能评价当前作物
生成器，不能评价原 replay 路线质量。

## 最佳基因

`GRG1-f7609f5b8d4ce762`：

- 阶段日：0 / 2 / 14；
- 三阶段工人：2 / 3 / 7；
- 最终作物：WHEAT 4、CARROT 1、TOMATO 3、STRAWBERRY 6、MELON 10；
- 最终 24 个目标全部位于 NW，无土地购买；
- 现金储备 300，购种前视 4 天；
- seed 17 筛选中最低现金 1,802，最终现金 29,151。

   不重新复用或切割其动作带。
