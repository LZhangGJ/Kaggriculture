# KAWASHIGI Counterfactual Route Ranker V2

目标不是继续模仿高手“当时选了哪条路线”，而是学习：在第 145 步的同一公开局面中，4 条可完整执行的 KAWASHIGI 路线里，哪条实际终局价值最高。

第一道关卡使用官方 Kaggriculture 1.32.7：

1. 四条路线第 0–144 步动作必须完全相同；
2. 同一对手、随机种子和座位下，第 145 步的公开状态与 66 维特征必须完全相同；
3. 四条路线从该点分叉，动态对手继续正常响应；
4. 用真实终局胜负优先、资金差辅助确定反事实最优路线；
5. 只有确认 Oracle 相对旧路线选择有实际提升空间，才扩展 JAX 数据并训练 LGBM。

边界：JAX 固定路线对手只用于扩大覆盖；官方动态对手结果是必需的困难负例和最终裁判。

## V3 验收状态（2026-08-16）

`PROMOTION_GRADE_PASS`：JAX 动态对手已通过官方 1.32.7 一致性验收，并扩大到 3,840 个上下文、15,360 局反事实续跑。V3 在完全独立的 384 局官方盲测中，相对固定后备路线：

- 胜率：28.65% → 51.04%；
- 平均分差：-3,691.88 → +189.46；
- 配对新增胜局 97、损失胜局 11，单侧精确检验 `p=1.20e-18`；
- 六类动态对手均未退化。

V8 强控件在相同对手池中的综合胜率仍为 62.24%，因此 V3 证明的是学习闭环有效，尚未证明综合强度超过 V8。详细证据见 `reports/KAWASHIGI_COUNTERFACTUAL_LGBM_V3_JAX_10X_ACCEPTANCE_ZH.md`。

## 23 对手盘面扩展与安全门（2026-08-16）

JAX 盲测曾显示 V4 和 hard8 有提升，但最终官方 Python 1.32.7 双座位复验给出了更细的结论：裸 V4 在普通随机 8 种子面板相对 V3 净少 9 胜，应拒绝；hard8 在普通面板不触发、完全保持 V3，而在按公开特征选择的 154 个触发上下文中净增 38 胜、只损失 1 胜。因此 hard8 通过“低频条件升级”验收，但仍需接入可提交 Agent，不能直接宣称超过线上 V8。

同时修正了安全门被大量零差值样本淹没的问题，训练现只使用 V3/V4 真正发生分歧的盘面；JAX 面板也改为每个随机种子只生成一次官方事件流，再跨对手复用，语义逐元素一致。JAX 阶段详情见 `reports/KAWASHIGI_BOARD_DIVERSITY_AND_TARGETED_GATE_BLIND_RESULT_20260816_ZH.md`，最终官方结论见 `reports/V3_V4_HARD8_OFFICIAL_1_32_7_VALIDATION_20260816_ZH.md`。
