# FC15 最早三场 Public 败局：精确反事实修复复审

日期：2026-08-23  
官方环境：`kaggle-environments 1.32.7`

## 1. 最终结论

最早三场败局不是同一个可以安全加入 FC15 的局部规则错误。

- kt-Kitayama 与 Sheep：FC15 缺少另一类从第 0 步开始的重作物/资本开局。FC16 的市场提前出售层完全无效；把 8牛6羊改成 10牛4羊也只能小幅改善，不能翻盘。
- Okan：FC16 因羊压力分支关闭市场覆盖，原局不变；Boatlee V21、Soil 与 Kaito 的完整动态经营可以翻盘，说明它同时包含后半段控制弱点。
- Soil/Kaito 开局能翻三场，但与 FC15 从第 0 步就采用不同投资。第 0 步双方同时行动，不能先观察对手再无损选择开局。
- 作物开局的五个兼容后半程对 FC16 仍只有 6.25%–25% 胜率；事后 oracle 也只有 31.25%。直接把 FC15 替换成 Soil/Kaito 会产生更大的 K320 弱点。

所以本轮的正确“修复”是：

1. 保留 FC15/FC16 主线，不合入无 Yarn 减羊、X562 后缀、B21 中盘接管等已被反事实否决的改动；
2. 把强作物开局作为独立互补候选继续开发；
3. 在作物开局共同前 96 步之后，研究公开状态路由和针对 K320 的新后半程；
4. 在没有跨随机库证据前，不宣称单 Agent 已修复最早三败。

## 4. 为什么不能直接把 Soil/Kaito 合入 FC15

FC15 路线 0/1/2 的第 0 步是：建牧场、雇 5、买 2 牛 2 羊、买 7 小麦种、12 瓜种、6 小麦。

Soil/Kaito 作物家族第 0 步是：单位 PASS、先买 14 小麦、雇 5、买 1 牛 4 羊、买 5 瓜种、5 小麦种。

两套路线从第 0 步就分歧。比赛第 0 步双方同时提交动作，因此不存在以下合法信息链：

`先看见对手首回合投资 → 再决定我方首回合走 FC15 还是 Soil`

若在第 1 步以后硬切，已经购入的动物、种子、建筑和现金承诺不同，不能称为无损迁移。

## 5. 作物开局是否能统一取代 FC16

Kaito/Soil 原始路线 9、11、17、18、19 至少共享前 96 步，可形成一个真实的作物开局路线家族。对 FC16 的探索库结果：

| 路线 | 胜率 | 平均分差 |
|---:|---:|---:|
| 9 | 18.75% | -5,386.88 |
| 11 | 6.25% | -6,068.78 |
| 17 | 25.00% | -5,066.00 |
| 18 | 12.50% | -7,207.12 |
| 19 | 12.50% | -7,220.41 |
| 事后 oracle | 31.25% | -2,461.19 |

即使事后知道每局最佳后半程，也远低于 50%。这证明当前游戏存在明显非传递克制，不能通过从五条旧路线里做 if/else 达成对所有 Agent 90%。

## 7. 下一步工程路线

1. 冻结 FC16：保留已经在 Moon 两个独立库上验证的市场改进。
2. 新建 Crop-Opening 候选：以前 96 步共同开局为基础，不改官方模拟器。
3. 从 FC16/K320 败局反推新的 crop-family 后半程，而不是只在旧 9/11/17/18/19 中选。
4. 新后半程先对 FC16、B21、Soil、Moon、Kaito 各双座位 256 局；再扩大旧本地全池。
5. 若 crop 候选仍不能同时覆盖 K320 与重作物对手，则明确保留两个互补提交，不用虚假的单 Agent 90% 目标掩盖非传递性。
