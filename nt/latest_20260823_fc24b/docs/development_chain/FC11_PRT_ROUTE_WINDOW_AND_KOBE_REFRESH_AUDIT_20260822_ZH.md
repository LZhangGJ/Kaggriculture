## 4. 可部署规则与模型复验

### step120

系统性单规则发现“第一家为BRUNCH_SPOT时锁定默认路线”的训练关联，但在
两个独立留出库上一降一升：一个下降约1.0个百分点，另一个只增加约0.4
个百分点。小树与LGBM同样不稳定，拒绝接入。

### step168

按已经公开的两家商店组成有序前缀，离线比较每个前缀下各路线的成对平均
得分；仅当支持度和置信下界过门槛才切换。该规则不使用未来商店、seed、
对手身份或终局状态。

- 训练库5折seed分组OOF：84.96% → 86.04%；
- 独立holdout A：85.94% → 86.91%；
- 独立holdout B：87.70% → 88.48%；
- LGBM在两个holdout分别为87.11%和88.48%，没有超过透明前缀规则的稳定
  价值。

因此step168前缀规则是可保留的小幅能力，但单独无法达到PRT 90%门槛；在
完成异质对手回归前不写入当前最佳配置。

极早重羊开局时启用。新增候选只扩展公开触发窗口，不修改两套规划器：

- start step：96/120/144/168/192；

   官方Python与CPU封装验收。
