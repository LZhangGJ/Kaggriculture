# T2 / R1 / R2：七对手同种子公平比较

日期：2026-09-09。本轮仅比较三个冻结默认版本，没有调参、修改策略或提交。

结论：**本批优先保留 R1 作为主版本，R2 作为可切换的实验分支。** R1 和 R2 相对原 T2 的平均胜率分别增加 5.29 和 4.86 个百分点，按种子分组的不确定区间均高于零。R2 相对 R1 少赢 6 局（−0.43 个百分点），区间跨过零，尚不能断言稳定强弱。

R2 相对 R1 的变化不是全面退步：G001 +1 胜、G003 −3、Boatlee +3、Kaito −10、Lynn 不变、Six-Day +2、Three-Day +1。主要回归集中在 Kaito；当前两个修复版对 G003 和 Boatlee 均未达到 90%。虽然 R2 的局部仓容预留测试通过，本批日末溢出累计反而高于 R1，不能把局部正确性说成整局物流损耗必然下降。

## 1. 测试口径

- 全新种子 `2609099000..2609099099`，100 种子 × 双座位 × 七个实时对手，每版 1,400 局，三版共 4,200 局。
- 七对手与此前测试一致：G001、G003、Boatlee V29、Kaito V58、Lynn V5、Six-Day、Three-Day。对手会根据真实盘面响应，不是冻结动作回放。
- C++ 官方 1.32.7 规则实现，16 线程；直接加载受测策略库，不重编译策略。每局独立上下文。
- 三版相同局面键，获胜要求正常完成 719 步且我方终局现金严格领先；平局不算胜。
- 三版先分别复现 14 场旧记录，共 42 场，动作哈希、现金等全部一致；这些旧局不计入新面板。
- 首个新种子的三版双座位七对手，共 42 场，另经官方 Python 规则核对 30,198 步我方动作和每日/终局盘面一致。这是新面板的子集，不额外增加独立样本量。
- 用户后来指定的独立 R1 包，与运行中的 R2 包附带 R1 全部 33 个策略文件逐字节相同，已单独保存确认记录。
- 没有运行 Kaggle 线上容器；本地时延不等于线上时延验收。

## 5. 版本身份

- T2：原 RecordedCandidate，33 个参数。
- R1：在 T2 上加入动物生命周期估值与实际维护对齐，`service_reconcile=2`，37 个参数。
- R2：在 R1 上加入混合货物一次 DROP 与同一步共享仓容预留，`batch_delivery=1`，38 个参数。
- R1 / R2 的 `live_ledger`、`delivery_calendar`、`feed_finance` 均为 0，没有启用被拒绝的实验分支。
