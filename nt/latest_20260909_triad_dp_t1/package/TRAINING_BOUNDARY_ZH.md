# 反事实估值实验的观测边界

这不是“看到真实未来的线上 DP”，也不是七对手身份路由器。

`policy/proposals.hpp::portfolio_features` 只接收 `dp7::View`、候选计划及 KEEP 计划。View 包含公开双方农场、公开现金、当时已解锁商店、市场及我方私有库存。不含 seed、对手名称、对手私仓、真实未来商店和对手策略对象。

离线 `Pool::collect` 才允许复制完整模拟器和完整实时对手状态。先冻结全部候选特征，再在隔离副本中测试本日经营计划；次日恢复共同基础策略。终局现金差用于监督标签，不进入特征。

`td_install` 安装经营计划，不安装原子动作 tape。强制 KEEP 与不中断参考过程的终局现金必须完全相同。改变候选评估顺序不应改变任一候选特征或结局。本轮小面板已有正序/倒序及 KEEP 检查。

训练文件 `features.npz` 与标签/seed/对手元数据分离。训练只读取 X；元数据只用于分组、分割和审计。分组训练验证不代表完整策略提升，仍必须重新进行实时整局对战和独立 seed 测试。

模型可选分支是 **DP 候选＋监督估值器**，不是纯 DP。只在实际整局验证优于原始公开信息前瞻时考虑晋级；未晋级模型必须标为实验，不能计入最终版本强度。
