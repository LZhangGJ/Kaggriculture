日期：2026-09-05。审查两份主程序与两份说明书。未修改被审查 Agent，未迁移 C++，未提交 Kaggle。

## 1. 主要结论

19万级打空气收益是真实可复现的。原说明书三组共150局在本地冻结官方1.32.7解释器中完整复跑，平均现金、中位数、极值、达到19万的局数均与报告一致。

两版是独立的动态规则 Agent，没有加载 Replay、外部策略、训练模型或真实未来。V2 并非 V1 各项能力的严格超集。两版在经营层和调度层选择了不同近似算法。

它们已经能自主生成有经济价值的混合经营安排，但没有验证主动对手胜率，也没有完整实现对手产能预测、主动抢卖和逐步全队联合重调度。

## 5. 两版实际在优化什么

| 层面 | V1 | V2 |
|---|---|---|
| 新增投资 | 每次比较一个新增项目的边际收益，逐个加入 | 对产业数量、预算、土地容量做离散DP，最多3轮重计价 |
| 作物周期 | Bellman递推比较少数周期、肥料和后续补种选择 | 使用作物预设周期进行产出预测；周期本身选择更少 |
| 现金周转 | 资金紧张时优先资金效率高的项目 | 状态决定远期收入折现率，重种成本按未来付款日期折现 |
| 人工成本 | 总工作负荷与近似非线性工资 | 按日工作量、访问量及斐波那契工资估计 |
| 路径 | 先选最多9个附近任务，用子集DP找局部路线，再逐人组装 | 在多个工人路线的不同位置尝试插入任务 |
| 动作执行 | 每步检查真实状态，空闲工人可接手待办任务 | 每步更新任务条件，缺投入不阻断其他可做动作，空闲工人可补位 |
| 物流 | 判断是否需要日内派人回仓，考虑溢出和终局 | 当日收获容量背包筛选，并保护维护投入 |

值得借鉴的是：从真实资产产生未来收支；把劳动力成本放入投资比较；把工人路线和物资取用关联；用小而清楚的DP处理确实可离散的小问题。代码约数百行即可兑现19万级收益，说明无需先堆积庞大的兼容控制层。

但“局部DP精确”不等于全季全队经营精确最优。V1路径目标主要是服务工作量；V2主要是插入距离/负载。两版均未对所有工人未来行为做全局终局收益搜索。

## 6. 已确认的问题与边界

### 6.1 两版没有直接使用对手农场信息

所有农场读取均指向`farms[player]`；没有计算对手即将成熟的作物、动物产能、人员运输或未来出售。

它们会根据共享市场价格、库存和商店变化再做选择，因此具有价格响应，但目前无法根据对手盘面提前预计一波集中出售。对空气成绩不能代替G001等实时对手胜率。

### 6.2 V2现有作物产量没有正确进入经济预测

源码 `crop_stream`（约137–152行）主要重新生成理想周期，再清掉过去的数组，没有按现有作物的`yield_units`纠正预期出货；与V1读取实际产量的逻辑不同。

用V2 seed61010、座位0、step408的真实成熟草莓做探针：该地块种于day7，在day17有2份待收草莓。仅把待收量从2改为0，其余状态不变，`forecast_base`的全部预测数组完全不变，总草莓预测仍为552。

这是经济估值的状态遗漏。底层HARVEST仍读取真实产量，不能说收获动作完全看不见产品；问题在上层会用未校正的未来现金作比较。探针没有测修复后能涨多少分。

### 6.3 V2市场现金预算高估批量卖货收入

`call`约504行按`数量×当前价`把销售收入加入可支出现金。官方是逐单位报价，大批出售会压价。

规则构造例：羊毛市场库存10000、现价200、卖100份，V2公式计入20000现金；官方对PASS对手逐单位结算为7969，相差12031。该例用于证明公式问题，不声称测试中真实发生过这笔订单。

V1出售预算已按逐单位价格求和，在这个方面更细。两版都仍需处理对手同时成交、仓库容量和部分成交。

V2还在发出土地购买请求时直接减少`buy_land`，没有逐笔以实际成交确认；若融资高估导致买地失败，日内重试和剩余承诺可能失真。

### 6.4 仍存在固定时机和日内调整限制

V2每个清晨全部人员首先PASS；有任务时最低雇5个hand；完整路线主要在新一天或人数改变时重新生成。收获准入集合也一天只生成一次。

V1主要逐人生成局部路线，日内做清理、绕开缺资源任务、回仓和空闲补位。它没有证明全队每步重新比较多种协作编排。

这些规则不直接等于bug，也可能是有效启发式。但不能把两版描述为完全无固定限制的联合规划器。V2的一天一次收获集合、清晨PASS、最低用工，以及V1的新动物截止门应作为独立消融项，而非未经验证直接移除。

### 6.5 尚无主动市场策略

出售主要是保护必要投入后及时卖出；没有完整比较等待涨价、部分出售、抢在对手之前卖、为了融资牺牲部分售价等互相耦合的选择。未来价格预测主要计入自身供给与城镇需求，也未纳入对手将来供给。

## 7. 建议

保留两版为两个独立经营基线。先用相同种子双座位对主动对手进行小规模比较，观察强自产收益是否转化为胜率，再决定主骨架。

值得优先验证的组合是V1的作物周期/局部路径能力与V2的组合投资/现金折现思想，但不能直接堆叠后宣称一定更强。先修复V2明确的估值遗漏和事务现金误差，再做单项、联合、多seed对照。

这次结论是“动态规则可以稳定产生19万级样本均值”，不是“已达到金牌实战强度”。没有执行主动对手对战，本报告不推断其胜率。
