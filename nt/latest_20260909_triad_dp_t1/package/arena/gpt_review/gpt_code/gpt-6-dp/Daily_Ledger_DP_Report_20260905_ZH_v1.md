**不能把“动作没有静默失败”说成“经营执行无损”。** 前者检查已发出的单位动作是否生效，不证明所有该做的任务都完成。死亡指标包含可能被主动放弃的低价值项目，未逐一人工归因；未喂养日也不等同于逃跑次数。市场订单的部分成交没有被包装成“零失败”保证。

终局地上漏收约10.44单位/局；仓库/背包为零不表示这些地上产量已经兑现。仍有优化空间，当前不宣称全局最优或完美清仓。全部逐日明细见 `results/audit50.json`，汇总见 `results/audit50.csv`。

## 7. 算法边界

本版本的两个实际DP是作物周期/重种日期Bellman递推与最多9节点的限时路径子集DP。整体投资组合是边际价值搜索，全队任务分配也是局部DP逐条构造，不是联合全局精确求解。

每回合根据真实状态检查前置条件，共享种子和仓库预留；不同工人可以接手同一生产过程，不复用旧脚本。未知商店使用规则期望，不知道真实未来。没有训练模型，也没有读取种子或对手私有信息。

尚未完成：主动对手对战验证、对G001胜率验证、完整SELL_NOW/HOLD市场路径DP、非默认规则覆盖、Kaggle沙箱实机时限测试、零漏收/零死亡目标。
