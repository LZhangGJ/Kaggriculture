# P2验收：代表可进入真实状态切换实验

日期：2026-09-05。验收通过的是行为代表与指定执行质量，不是胜率目标。

## 聚类选择

实际经营序列的12档距离阈值均已检查。0.10得到29族，seed半分ARI=0.97957、轮廓系数=0.71386、最大族19.41%；0.12得到17族，综合分略高，但差距在冻结的5%范围内，按预定规则选择更细的0.10。没有人为规定29族，也没有单一超大族吞掉大部分样本。

现金和胜负没有用于聚类距离。每族先取靠近中心的四分之一，再按生产动作可靠性、最弱对手/总体胜负和分差选代表。29族全部保留，包括11个单例族；没有因为总体胜率低就删除稀有策略。它们在发现集联合覆盖56/56世界，已无需再添加补救成员；这不等于任何一个Agent全胜。

## 新种子复验

29代表+DP27/J7_03/KEEP，共32套，在16个全新seed、双座位、七实时对手中完成7,168局。所有代表的验证期经营轨迹，最近的发现期家族没有改变。距离和具体产业、购买、人员、销售、残余统计见quality_evidence.json。

全7,168局的PLANT、动物PLACE和BUILD精确投影无效果计数为0。另对每套代表的2个验证seed、双座位、七对手共896局，补查全部实际发出的单位动词，包括移动、浇水、喂食、收获、拿取、放下、施肥、CARE等：无效果计数为0；逐局完整动作/状态hash与终局现金等于C++实时对战源。核查不修改策略，不向在线决策输入未来信息。

这仍不是对所有未见局面的无硬伤证明，也不说明它们已经具备最佳调度。

## 软经济问题不冒充硬错误

开局38的224局中，有257条订单部分成交、111条订单现金不足，平均每局5.15625个日初recipe不可用；小量作物携带物和未放置动物可能残留。所有可出售shed产品的平均终局数量为0。这些记录保留，不一刀切清除策略，更不把recipe字段当成实际已兑现动作。

因此下一步要测试：接某个后缀后，是否真正适配当前现金、产业和人员，是否救回败局或损失胜局。本阶段不修改底层执行器，不按单局结果特调。
