# 动态三日计划特征实验计划

## 目的

队友的切换树使用固定动作路线，因此能直接扫描未来24、48、72步的市场订单。当前S9使用动态日计划，不能把任意固定动作带冒充真实计划，也不能运行隐藏未来获得特征。

本实验在冻结S9之外增加18维合法在线特征。每个24/48/72步窗口记录：

1. 计划总支出；
2. 扣除计划卖货后的最大资金需求；
3. 当前现金减最大资金需求；
4. 计划雇工数；
5. 计划扩地数；
6. 计划买入动物数。

## 合法投影

输入只包括当前真实可见盘面、我方私有库存、当前控制器状态和当前29日经营策略。投影逐日调用与正式执行相同的候选生成和订单编译器，但只结算我方计划市场订单；不执行单位动作、城镇需求、杂草、随机商店、对手未来动作，也不读取对手私有库存或种子。

第一天订单与正式控制器准备队列一致。第二、三天是假设已下达市场订单成功后的条件性计划承诺，不是未来状态预测。未来recipe在投影状态不可表达时回退KEEP，并单独记录`forecast_missing`，不得静默伪装为精确预测。

## 三组消融

- `current146`：冻结S9的129维盘面/历史 + 17维控制器状态；
- `plan147`：129维盘面/历史 + 动态三日计划18维；
- `fused164`：129维盘面/历史 + 动态三日计划18维 + 17维控制器状态。

模型、目标后缀、训练种子、选择种子、检查日和浅树容量保持一致。先在TRAIN拟合、SELECT冻结；只有冻结后在既有未见随机种子双座位holdout中同时满足总体增益LCB>0且最弱对手不退化，才允许接入Agent。否则保留原最佳，不晋升。

## 工程验收

- 新探针的`current146`逐键等于原反事实表特征；
- 1线程/16线程、正序/逆序种子特征完全相同；
- 修改三日窗口之外的recipe不改变当前18维；
- 无规则时新运行入口与冻结S8/S9完整719步结果及hash一致；
- 所有特征有限、维数准确，`forecast_missing`显式报告；
- 原S9源码、模型和收据不修改。
