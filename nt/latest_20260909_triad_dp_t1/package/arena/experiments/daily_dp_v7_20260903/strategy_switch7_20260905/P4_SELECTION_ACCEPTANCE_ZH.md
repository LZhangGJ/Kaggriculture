## 可以和不可以下的结论

可以确认：真实状态下某些后缀确实可以救回很多败局；但是本轮浅树及检查点组合没有可靠兑现。直接C++完整执行与首次切换查表结果逐局动作状态hash、现金、实际目标及切换日完全一致，因此差距不是查表偷偷做了多次切换。
不能确认：加大树或增加样本一定会解决；不能从这些结果单独断言缺某一个特征、全部候选空间太小或底层一定有错误。训练标签是各时点最优后缀分类，压缩后缀只用4个发现seed，树的表征、标签多解和压缩选择都可能是后续审计方向，尚未证实各自因果。
按事先规定，无可靠增益不晋级切换。保留7棵训练树及全部127个非空组合供研究，不把其中测试最好的一套冒充独立验证通过的Agent。
最终Agent若不切换，部署验收只能证明固定经营计划加动态执行的实际路径；不能借此声称部署版树分支均已通过真实切换测试。
本轮最强仅指固定开局与训练出的检查点组合，在预先定义的最弱对手优先及稳定增益门内选出的结果；不是全部1,494套、全部32后缀和所有可能树的全局最优。原DP27和J7_03继续保留，不因本轮实验覆盖。
