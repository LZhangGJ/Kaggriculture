## 限制

聚类不用胜负/终局现金作相似度，但代表筛选使用发现集成绩。83,664局指定生产意图诊断、7,168局代表复验，以及896局全部实际单位动词效果和完整hash审计均通过；后者不是全量83,664局覆盖，不能宣称所有硬伤已穷尽。宏观recipe不适用会显式KEEP回退。
单次切换Oracle可以事后挑时点及后缀，仅衡量有限候选库的表达上限。小树与实际胜率单独验证。分座位/分seed数据、救回与伤害表和置信区间都保留。若选型最终保留不切换，正式部署不含树，不能宣称部署版树的切换分支已实战验收。
置信区间按独立seed分组，座位不当成独立随机样本。全胜bootstrap退化不是真实胜率100%的证明。
部署为依赖本地冻结工作区的WSL Python入口，不是独立Kaggle提交。未提交Public，未推Git。
