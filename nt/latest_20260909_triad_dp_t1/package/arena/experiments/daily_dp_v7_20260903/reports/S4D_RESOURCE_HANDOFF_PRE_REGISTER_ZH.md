# S4D：真实盘面中的带资源任务交换

本轮继续当前八对手实战目标，不做 Candidate 后缀、事后终局选优或单 seed 固化。

S4A–C 的逐步重协调主要重分配不消耗随身材料的任务，FEED/FERTILIZE 等仍锁在已编排的工人。先检查这个限制是否在真实局面造成可修复的路程浪费，不预设它就是主要败因。

## 第一阶段：只读机制审计

- 使用当前 old、all_guard 两种真实执行轨迹；开发 N50，八对手、双座位。所有对手完整实时决策，不回放固定动作带。
- 每天首个完成编排后的实际状态，以及日内 6/12/18 时点检查。此抽样只用于诊断，不是策略触发日历。
- 从当前剩余动作提取地块服务组。枚举不同工人间相同材料/操作序列的组交换，例如 FEED、FEED+CARE、FERTILIZE+WATER。保留全部原任务及每位工人的材料动作，不允许瞬移小麦/肥料。
- 先用本方可见状态检查材料前缀、全局种子与仓库预留、全部剩余任务的截止时间、同地动作先后、衰败边界；再只对候选中最省时的一项与原安排做冻结官方 C++ 单位阶段投影检查。
- 投影不推进时钟、市场、对手或随机事件，不续跑到终局，也不参与本轮 Agent 决策。不能据此声称终局收益上限。
- 统计检查局面、可交换组、合法交换、确实省步的局面、节省团队总步数/最长路线步数、投影无效操作及动作效果是否一致。保存具体例子。重复时点的潜在省步不能相加当作整局真实收益。
- 核对真实终局现金与之前同配置同 seed/座位面板逐局一致，确保审计不改变原对局。

## 进入实际开关的条件

若发现跨多 seed、多个对手的可行交换，再接入独立开关并做机制测试、官方抽样、独立与四能力组合实战。若机会极少，只据此否定这个有限交换方案的收益空间，不宣称完整多人规划无价值。

最终标准仍是同一 Agent 对八对手各自 >90% 胜率；省路、投影正确和被动对手现金都不能替代它。O/P 独立确认集本轮不用。

## 第二阶段预注册（取得机制证据后，尚未查看新策略强度）

N50 的 1,600 局只读诊断已完成。八个对手均存在跨多个 seed 的带料交换，投影效果相同且无新增 no-op，但通常只省约两个动作、很少缩短最慢工人的路线。因此只作为小范围补缺，不预告强度突破。

新增 `resource_aware_exchange` 独立开关：每步从真实位置重建尚未完成的任务，枚举相同输入服务组交换；全部旧任务保留，材料/因果顺序/期限检查通过，且团队总动作严格减少、最长路线不增加时，采用一项交换。没有 Simulator、种子、对手私有状态或终局回报输入。每步最多接受一个交换，重复步数累计只作诊断，不能折现成现金。

同批对照六项：old、仅交换、all_guard、all_guard+交换、all_midroute_net、all_midroute_net+交换。仍为 N50 × 双座位 × PASS及八对手，每项每对手100局。先机制和官方抽样后跑整局；只读重复账目与原面板逐局对上。不开 O/P。
