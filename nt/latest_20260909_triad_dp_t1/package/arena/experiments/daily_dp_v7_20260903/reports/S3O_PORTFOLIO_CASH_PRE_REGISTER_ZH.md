## 本轮可否证假设

现有 `temporal_values` 逐日模拟一个新增项目的收入/支出，但没有把新增项目改变市场后，已有项目未来售价变化完整记入边际收益。只赚到“新增项目收入”不等于“整套经营净增益”。

这是代码可定位的估值遗漏，经济影响未知。旧的分日期估值曾失败，因此必须保留预测口径匹配的控制组，不能把重新开启旧功能当升级。

本轮增加两种共用日历与报价模型的估值分支：

1. `cashflow_value_mode=1`：只记新增项目自身的预测现金，用作匹配控制。
2. `cashflow_value_mode=2`：上述现金，加上新增项目使已有组合现金改变的部分。
3. `mode=0`：完全保留旧估值和原执行。

三者不改开局、候选产业、实际任务编排、买卖执行、对手供给权重或雇工。日历仍是条件预测，不是实际未来；不声称已经实现联合融资/最优调度，也不声称产出当天一定能销售。
