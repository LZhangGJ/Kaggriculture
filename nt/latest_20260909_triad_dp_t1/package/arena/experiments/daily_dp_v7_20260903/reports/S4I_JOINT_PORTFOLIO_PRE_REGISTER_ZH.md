# S4I：完整投资组合开关——实施与有限对照

## 改动与边界

`joint_investment_portfolio`默认关闭。保留旧方案与不新投资的KEEP；在当前预算、空闲地块、8产业数量上限内生成整数数量组合。宽度8的数量向量搜索先用便宜供给曲线筛选，最多8个非空候选加各产业一个单产业候选，再用真实采购投影和排班检查。

这不是Oracle：运行时只有当前公开盘面、自己的库存、当前商店；没有真实未来、seed、对手身份和隐藏库存，没有按seed取赢家。也不是完整全局最优：首层评分与宽度会漏组合，既有布局与土地范围仍继承原计划，尚不搜索新布局或全部跨日策略。

## 与旧评分不同的可检验内容

- 全组合按日合并供给/饲料，不再逐个项目独立买入小麦又卖出同日自产小麦。
- 对整个供给计算价格变化，也计入对已有我方产出的价格影响。
- 产量到达收集阈值才预计收获，日末入库后下一日变现；终局保留显式搬运窗口。
- 今天必须通过已有采购投影、资源预留、排班开工检查；保留已有维护动作。只在事前条件预测中计算现金，不把预测资源写入真实账本。
- 未来以同作物续种、正常维护的条件日历生成地块作业集，共同排班估雇工费用。该日历不含未知杂草、对手新投资或真实未来交易，不能称逐步精确模拟/保证兑现金额。
- 四项执行开关仍独立；新投资组合的角色是提供更好的工作集，不把整条生命周期固定给一个人。

## 尚存估计误差

当前已有资产的供给预测沿用上一版；新增资产采用收集/回仓窗口，两者精细程度不一。未来排班假设供料足够、日初站位按规则重置；未来价格、仓容竞争及真实出售时点不保证与预测相同。未来雇工费是条件估计，不是只要缴钱就必定完成。KEEP保留不能防止估值错误导致实战退化。

## 冻结与验收

前置修订：S4I1的4480项机制、32局性能探针已保留，最高原生单步约52ms；未作强度选型。复查发现新现金净额评分继承旧的`own_feed_demand_weight=0`会漏已有动物维护，因此正式S4I2将新评分中的已存在动物饲料设为真实完整义务。旧策略及开关关闭时不变；这是纠正新账本的遗漏，不扫描权重、不依据某seed胜负改参数。S4I1只作为前置检查版本，不晋级。

先完成小规模穷举对照、资金/土地限制、八产业覆盖、供给和饲料净额、回款时间、开关不影响旧版测试；再探测每次规划耗时和完整局。成本不可接受则先优化重复计算，不直接启动大面板。

之后冻结有限配置：`intraday_funded`和`all_intraday`两个上下文，各原版、自主开局、投资组合、自主开局+投资组合，共8配置。N50（20262701–20262750）×双座位×PASS与八实时对手；每配置900局，合计7200局。此前已见N仅开发，不是独立确认；O/P暂不使用。旧版两上下文对照必须逐局与S4G一致。

报告单项、组合、交互及成本，重复现金/产销对账，官方逐步核对。未达到同一Agent对八对手分别>90%则Goal继续，不以某对手改善晋级。参数、失败配置和原始结果全部保留。任何新增配置必须另行登记，不能看结果后暗改。
