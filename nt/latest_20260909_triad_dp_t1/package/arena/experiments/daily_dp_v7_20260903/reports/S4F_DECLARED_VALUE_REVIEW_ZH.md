## 机制与证据

旧日内估值会遗漏已排入、尚未 PLANT/PLACE 的自身项目。先运行只读观察器：2700局、1,941,300次动作与关闭观察器完全相同，终局也与S4E相同。观察器只比较同一真实当前状态下的解析排序，不续跑真实未来。补记只影响少数新投资选择；单采购组合对G001仅2/100局，对G003为11/100局，复杂组合分别5/100与14/100局。不能据此称它是主要败因。

补记包括当步已发出以及剩余计划中的项目、产出和饲料义务；不把未成交资源写成库存，不重复计入同一地块，不信用跨日来不及执行的动作。
