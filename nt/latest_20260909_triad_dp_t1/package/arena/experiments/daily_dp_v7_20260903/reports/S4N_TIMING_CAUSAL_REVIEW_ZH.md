# S4N：调度改变了什么——冻结逐步复盘

2026-09-04。128场实时原对手重跑全部完成；64组成对比较，开发N前8 seed、双座位、G001/G003/Boatlee29/Six-Day。无新政策，无事后续跑选动作。

## 实际证据

- 每场719动作及双方终局现金逐场复现S4M1；另128场原生完整账本重跑，3840个日界的双方现金、我方私有物品、地图产品、种子全部匹配，overflow也与面板一致。重复不增加独立样本数。
- 64组首个单位动作差异均在step27，首个物理地图差异均在step28。
- 首次市场分歧中，31组仅新策略买1胡萝卜种子；16组仅旧策略买1胡萝卜种子；13组仅旧策略买1小麦种子；2组仅新策略买1小麦种子；余2组为出售13/14蛋的数量差异。
- 因此“首先是抢卖时点变好/变差”的假说不成立。更直接的链条是：共享编排改变人员空闲时点→日内投资触发不同→盘面与后续生产改变。
- 这不证明买或不买某种种子必胜，不能从这些对局写入作物、日期或对手规则。小批归因不替代完整N50胜率，不能按单局最终钱差给第一步分歧分配全部因果功劳。

## 源码缺口

`intraday::propose`检查当前现金、材料预留、市场槽位、今天剩余工时，但复用单项目`action_shadow * actions`估算未来劳动。没有将新项目加入整片农场、比较实际地块上的未来人员需求和阶梯工资。

现有`portfolio::future_wages`已提供按日期、实际地块、维护/收获工作集和当前pack估算的条件人员成本；它仅接在日初组合投资，没有接入日内追加。不能重新发明一套作物成长规则，也不能混淆“未来模型估算”和真实未来。
