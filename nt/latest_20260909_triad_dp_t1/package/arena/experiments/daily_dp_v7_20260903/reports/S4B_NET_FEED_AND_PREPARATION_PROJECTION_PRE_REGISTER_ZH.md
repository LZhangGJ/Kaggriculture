# S4B：已存在产能的净备粮＋采购期出生位置一致性

2026-09-04，观察本轮强度结果前登记。不是 Candidate/事后 Oracle，不做固定路线搜索。

## 假设与证据

1. S4A4B 旧版 N50 对 G001，销售总额135,509，高于对手133,402，但支出34,720，高于对手28,447；小麦采购12,617对4,322。会计差额不等于可回收利润。
2. `orders` 的备粮目标为每日喂料需求×覆盖天数，未扣除已经存在的小麦田未来供给。只有未来价格预测参考了产出，数量库存目标没有参考。可能发生重复占用现金；也可能是在提前便宜买粮，必须全局对照。
3. 采购并行用“移动前的位置”投影 HIRE 出生点，却可能同一单位阶段离开/进入中心四格，从而改变随后 HIRE 实际出生点。虽然下一帧重新编译，当前提前移动不一定是投影编排的有效前缀。

## 独立开关

- `net_feed_buffer`：只改变原先允许投机备粮时的目标数量。对已存在的我方小麦田，用当前计划收获年龄和产量预测生成到货日；收获当天不能用于日初备料，最早次日入账。总目标取逐日前缀的最大饲料缺口，并保留当日全部必需饲料。不计未来尚未种下的小麦、不计对手库存、不读取未知事件。
- `preparation_spawn_guard`：仅用于 `preparation_pipeline_v2`。剩余订单有 HIRE 时，不允许提前移动改变中心四格占用计数；非中心移动和非移动生产仍可执行。默认关闭，用于同批因果对照。
