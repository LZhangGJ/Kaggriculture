# S3V：空闲工人回仓有微小收益，但不是主要突破

2026-09-04。本轮开发与新seed复验完成，正式目标仍未达到，不晋级为新的强度基线。

## 1. 结论

新增“预计溢出时，安排空闲工人提前回仓”的独立开关，并与联合排班做2×2组合。它没有覆盖正在执行的任务，也没有额外雇工，但增益很小：同批PASS平均多138元；G001、G003胜率不变，Kaito只多1/300胜。

因此保留能力和所有实验结果，不继续对运输阈值做细碎调参。下一轮仍以S3U的terminal_only为对照，这一轮在新配置文件里叫`old`。不能拿更换seed后的绝对分数当作新版本改善。

## 2. 为什么做，和旧方案有什么不同

这是A集各100局的实物/现金描述，不是“把这些货救下来就一定追回相应分差”的因果保证。G003对局的工资差只约592元、商品采购支出差约4,583元、销售收入差约23,122元，不能把所有差距归为工人走路。

旧S3C曾给全部生产预留回仓并增加雇工，虽减少丢货却降低现金。本次不重复那种做法：只在已有任务结束后，利用剩余时间追加回仓，原市场继续按真实状态处理，不修改经营比例、雇工估计、目标日期或对手。

## 3. 实现边界

`overflow_idle_dispatch`默认关闭。开启后，每步估计自己的已携货、剩余计划将收集的当前可见产物、输入消耗及已有回仓；预计超过容量时，才检查空闲单位。

单位必须已完成原计划、持有非空且可整包入库的货物，并能在日末前至少提前一步抵达仓库。按运输份数/所需动作数选择可用运力；这只是物流启发式，不宣称是现金最优选择。它不抢占在途维护、不增雇工、不新增生产项目，也不在终局覆盖S3U波次计划。

估计不读取真实未来、对手隐藏库存/身份，只依据当前信息；未将有限作物后续浇水新增产量等全部模拟进去，也不保证已有DROP一定成交。因此必须用实际对局验证，而不能把这个预测称为精确全天物流模拟。

## 5. 为什么效果小

A集原排班上开启空闲回仓：

| 对手 | 每局追加回仓 | 原日末丢货 | 新日末丢货 |
|---|---:|---:|---:|
| PASS | 0.22次 | 45.3 | 44.3 |
| G001 | 0.09次 | 50.0 | 49.8 |
| G003 | 0.27次 | 59.4 | 58.6 |
| Boatlee | 0.13次 | 71.0 | 70.7 |
| Lynn | 0.17次 | 73.6 | 72.9 |
| Fieldbook | 0.17次 | 48.5 | 47.6 |

可以确认的是：**本能力实际触发很少，覆盖不了大部分现有丢货。** 尚未把未触发原因完整拆成“预计低估”“工人没有足够空闲时间”“已有回仓被误认为会成功”等各项，因此不能未经进一步审计直接说全部由某一个原因造成。

同期未排入任务数基本不变。被审计的已发出生产操作无效果计数为0、动物逃跑计数为0，但这不等于所有策略硬伤清零。修改现金/市场之后，后续投资和生产仍可能改变；不能声称整局所有生产完全一致。

## 6. 负例也保留：少丢货不一定多赚钱

选取A集现金下降最多的例子之一，20261416、座位0、G003，原/新两局均经官方完整复验。

- 第305步第一次分歧，之前状态和动作完全相同；第9号单位从PASS变为向西回仓，其余单位动作不变。
- 新方案全局少丢4草莓、8牛奶、6肥料；并非因为增加了种植、动物或喂养规模。
- 我方现金119,869→119,369，少500；对手137,394→136,516，少878；我方分差反而改善378，仍然输了。
- 我方草莓销售收入少373、牛奶少219、肥料多92，合计-500。对手产出数量不变，但同类商品销售收入下降；不是“对手少生产”才改变分差。
- 我方草莓生成量也少2份，说明后续执行有连锁变化，不能把全部效应都解释成纯粹的提前卖价。

这是生产、物流、市场共同作用的实例。没有因此给该seed、G003或某个固定日期加特殊规则。低丢货率、较高现金、较好分差必须分开报告。

## 7. 工程验收与执行成本

- 4,242项机制检查通过；新增检查覆盖任务不能被覆盖、已有回仓不重复派遣、时间边界、资源消耗、可见产物去重和关闭开关不干预。
- 32局常规官方完整719步检查通过，另2局上述负例官方诊断；六个迁入对手隔离/复位检查通过。
- A/B7,200条配置对局，原两个端点3,600条逐局复现S3U，不能算新独立强度样本。新L3,600条，总计10,800条配置对局。
- 3,600局重复现金/生产审计全部对账、与面板现金一致，不增加独立样本量。
- 本轮构建23.04秒，A/B各3,600条全局执行约12.23/12.26秒，最多16线程；重复审计程序约78.25秒。
- 单配置A批G001热循环约原版715局/s、空闲回仓746局/s；只有一轮计时，差异包含机器噪声，不能据此声称新功能提速。代表负例原生决策抽样最大约6.6ms；尚未完成Python提交版及线上1秒验收。

官方规则和原对手未改，最终独立验收集仍未使用。本轮无训练、无Kaggle提交、无Git推送。
