# S4G：让已有动态选择器处理开局，预登记

## 问题证据与范围

S4F复盘确认：`choose_impl` 在第0天、农场无动物时，忽略所有投资估值而读取固定开局。这一限制应与“日常选择器是否足够好”分开实验。不能仅把高手牛羊/甜瓜数量换入配置称自主规划。

新增独立开关 `autonomous_start=false`：打开后初始状态也进入与以后相同的八产业、现金、地块、数量上限及公开供给估值流程。其他数量、截止日、开关全部不变。不新增固定作者模式，不使用真实seed、未来随机数、对手身份或候选后缀。

## 可证伪预期

1. 开关关闭逐局复现S4F控制。
2. 打开后不再读取opening数量；相同公开/自身状态必定同样选择，改变现金、市场或资源限制可以改变选择；种类上限仍有效。
3. 若全季净收益排序把有限开局资金投向过慢项目，自主开局可能反而变差。必须报告，不能继续隐藏地调固定数值。
4. 已有资金投影/可执行工作集比较 `funded_bundle_mode=2` 可能与自主开局互补：保留四能力等复杂组合，成对测试它是否改善新的开局兑现。
5. 已有日历估值仍为条件估计、不是精确回款；只增加一个预先指定的日历评分对照，不开展比例、日期、数量的大网格。

## 冻结配置

基于S4F `intraday_funded` 与 `all_intraday` 两个上下文，各测试四项：

- fixed：原固定开局。
- auto：仅打开autonomous_start。
- auto_funded：autonomous_start＋funded_bundle_mode=2，比较资金与排班能兑现的工作集。
- auto_calendar_funded：上一项＋cashflow_value_mode=2（已有自己总现金边际估值，不重新实现预测）。

此轮是八配置7200局：N=20262701–20262750、双座位、PASS及八个实时对手、C++最多16线程。保留逐配置结果；后两项是组合研究，不能把全部变化归于autonomous_start单项。不开新O/P。

先机制检查、官方1.32.7逐步核对和迁移隔离；再强度对照。记录首次投入结构、前12天真实现金/销量、终局胜负与分差。择优只看多seed总体，不能按对手或seed在配置之间挑胜者。新配置若明显退化，保留失败证据而不晋级。未达八对手分别>90%继续保留goal，不能用PASS收益替代目标。

## 后续边界

本轮不以运行时续跑真实未来选择开局，不重启Candidate Oracle。更复杂的回款日历或自主项目搜索必须依据本轮真实结果另行设计；当前只检验“固定开局绕过规划”这一结构性限制。
