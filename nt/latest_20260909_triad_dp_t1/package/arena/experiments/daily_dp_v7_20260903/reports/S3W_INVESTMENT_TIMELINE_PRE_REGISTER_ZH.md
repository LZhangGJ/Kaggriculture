# S3W：先测投入和回款时间，不先认定是执行错误

2026-09-04。正式目标、对手和未用最终验收集不变。

## 第一部分：冻结只读诊断

对S3V原版A集900个已有完整条件重跑只读C++审计。保持政策源码、配置、官方引擎、八个对手不变，新增记录不进入决策输入。逐局比较终局现金、溢出以及现有现金/生产账。

记录日初空地或不同产业地块上的新目标；真实PLANT/PLACE；每个真实投产批次首次可见产物、首次收取；市场请求实际成交量。实际购买和实际投产均保留原始时间，种子/动物延迟按FIFO记账计算（是物料年龄约定，不声称可识别单个种子）。

日初目标仅统计空地/不同产业，不能据此代表同产业所有补种。相同格子同产业过几天开工，仅称“后来同格同类开工”，不能证明中间目标一直保留。实际投产批次独立统计，包含补种。货物可混合，第一笔销售只做商品级时间统计，不捏造地块级利润归因。动物肥料也可提前融资，主产品的等待时间不等于完全没有收入。

## 判定与后续

如果已买物料普遍及时投入、已投产批次普遍及时收获，不继续把主要问题叫“买了却没开工”；转向项目组合、产能和现金回流选择。

如果出现重复延迟，再用真实延迟类别提出独立改动，同时保存旧行为及相关2×2组合。不会仅凭日初现金低就强制增加现金保留额；低现金可能是有效投资。不会重复S3Q“只缩放当天能开工的前缀”，也不直接播放高手日历。

这一阶段是诊断，不是新的强度试验，900局不增加独立样本量。先完成数据一致性，再决定下一项机制实验；不得用解释替代胜率验收。

## 第二部分：时间线完成后的机制假设（结果未运行前登记）

只读900局逐项复现旧账。对G003，已成交牛/羊当天放置约99.0%/98.8%，种子多为当天投入；草莓首收比首次产出晚约2.24天，符合现有攒量执行逻辑，不直接视为硬错误。第12天结束累计销售收入我方10,444、对手36,093；累计种子/动物/土地投资我方10,015、对手14,737。因此不能把现金缺口解释成“我方只是多买了资产”。

新增假设：旧贪心主要按全季净收益排序，未显式比较项目占用现金的时间。增加独立`capital_time_rank`，使用既有公共信息现金情景计算项目每天尚未收回的投入之和。新排序为：

`净收益 / (1 + 未收回投入的元·天 / 当前剩余可投资预算)`。

这是资金受限时偏好回款较快项目的启发式，不是最优性定理。预算较大时趋近旧排序；动物肥料的预计回款也计入，不只看主产品。沿用原现金情景的局限：没有精确预测将来的多人运输、出售顺序、隐性工资、未来对手行为或真实商店抽样。不会因为这个分数就认定哪个项目真实最优。

四组：old；仅现金日历估值（既有mode2）；仅资金时间排序；二者叠加。以同批A/B各50seed双座位、PASS和八对手比较。后续不调参的新M=20262601–20262650复验。M一旦使用属于开发，不动最终验收集。

不改开局参数，不改已投入资产义务或底层动作，不按身份路由，不扫现金阈值。原净收益仍用于土地净收益比较，排序分数不能冒充元钱。独立开关关闭时必须复现原对局。单项或组合失败均保存，不将资金紧张直接改成强制留钱。
