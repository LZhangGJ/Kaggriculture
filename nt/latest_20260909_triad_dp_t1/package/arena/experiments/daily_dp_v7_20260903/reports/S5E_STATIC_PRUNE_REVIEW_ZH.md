# S5E 静态候选剪枝：隔离与真实状态等价验证

2026-09-04。完成隔离原型和真实状态验证，**还未接入正式Agent，未做新整局吞吐测量，不晋级策略**。

## 依据与改动

B的候选选择使用静态任务分，日内条件推演只负责安全检查。旧实现即使候选静态分不超过当前最佳，也仍执行整天条件推演；结果无论安全与否，都不可能替换当前最佳。

隔离原型按原始候选顺序遍历，沿用完全相同的 `score > best + 1e-6` 规则，只跳过这种不可能胜出的候选。首次出现可能胜出的候选才计算KEEP安全基准。所有可能胜出的候选及必要安全检查保留。没有按对手、seed或路线截断；没有调整分数或动作。不能改成按分数重新排序，因为近似平局容差下那可能改变原选择。A使用另一种估值，所以原型遇到A直接执行原实现，不作该剪枝。
