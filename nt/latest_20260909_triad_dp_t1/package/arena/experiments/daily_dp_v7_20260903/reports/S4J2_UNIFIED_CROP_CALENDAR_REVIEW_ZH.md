# S4J2：作物估值口径修正有局部收益，但不晋级

2026-09-04。当前 Goal 继续 active，距离同一 Agent 对八个对手分别 >90% 仍远。没有提交、推 Git、训练模型或启动 Candidate 事后 Oracle。

## 一、改了什么，为什么改

S4I 的新组合规划比旧对照差；真实账本显示更多小麦、更少草莓。S4J1 审计确认，它给新项目计算后续多茬产量，却给已有作物主要计算当前茬，而人工负担又按续种处理。这不是一致的经济比较。

S4J2 新增独立开关 `portfolio_crop_calendar`，默认关闭。组合规划中的新/已有作物共用 `crop_delivery.hpp`：用已有 `Controller::jobs` 生成维护、收获和重种工作，再按冻结规则预测单地块成长、腐坏、收获、种子支出、肥料消耗及入库日期。日历也用于条件人员负载预测，不再只额外补一个静态总产量。

保持 S4J1 的开关边界：`autonomous_start=false` 时，组合规划不能偷偷替换开局。四个执行能力开关均保留，未修改对手、规则引擎、固定开局参数或对手专属条件。

边界：这是充分供料、无未来杂草、同作物延续的条件预测；不是对真实未来的访问，也不是未来现金/物流必然可行的保证。新增日历目前用于组合规划，不能声称旧日常选择器和日内准入中的全部估值都已统一。已有项目的未来种子成本有记录，但共同基线成本在新增组合比较中相消；未来现金足以履行所有承诺仍未验收。

## 二、实际测试，不靠单局择优

- 12 个预登记配置：两种执行背景 × 固定/自主开局 × 原对照/组合规划/组合规划加统一日历。
- 对 PASS 与全部八个原始实时对手：每格 N50 双座位，共 10,800 局，16线程，面板约194.26秒。
- N=20262701–20262750 已是开发集；每格100局是50个独立seed簇，不是100个独立seed。O/P未使用。
- 四个无组合规划对照共3,600局，与S4G逐局现金、对手现金、胜负及溢出一致。
- 新日历四组另跑3,600局只读账本审计，约186.13秒，结果与面板逐局相同，现金/产物账全部闭合。重复审计不增加独立样本量。

## 三、它改善的是什么，未改善什么

以自主开局、四项执行背景对G003的100局为例。旧组合日历的历史对照另外核对了当前面板逐局一致，才复用其账本。

| 实际量 | 修正前 | 修正后 |
|---|---:|---:|
| 小麦产量 | 861.95 | 695.92 |
| 草莓产量 | 77.88 | 132.70 |
| 牛奶产量 | 238.44 | 248.70 |
| 羊毛产量 | 110.50 | 130.06 |
| 小麦日末容量损失 | 48.94 | 12.17 |
| 牛奶日末容量损失 | 36.60 | 21.55 |
| 草莓销售收入 | 12,363 | 19,182 |
| 终局现金 | 82,143 | 92,209 |

实际现金变化：销售+10,643，种子支出+245，动物支出+588，供料支出+43，工资支出−299，土地不变，净现金+10,066。说明改善并非预测器自己报高分，而是完整局的产业结构与兑现发生变化；但不能把某一作物收入差单独视为可独立回收的因果收益。

这也体现长链：第11天现金约−1,078，第19天约+1,278，终局才+10,066；仅看前期即时现金会得出相反结论。

不过，同局G003仍平均108,198，当前自主版92,209，差15,989。保留强对照自身对G003约102,582，仍强于修正后的新规划器。新规划器少买饲料并不足以获胜；相对强对照，销售额减少约16,641，节约供料约5,664，净现金仍少约10,373。不能继续概括成“工人没走最短路”，也不能直接规定草莓必须种多少。

## 四、工程验收与性能

- 120个合法采购起步的受控C++整局、五种作物、多种浇水/翻种/施肥开关，127,475项条件日历检查通过。受控测试关闭随机杂草、冻结估值报价，不是120场强度评估。
- 原有4,490项机制检查通过。
- 首次新增测试失败是测试 Controller 漏设day，默认−1；已补合法时钟检查及测试初始化。失败日志v1保留，不覆盖；通过的是v2。
- 八个对手各4局、共32局官方1.32.7逐步状态/对手动作抽样对照通过；六个迁入对手的隔离检查通过。不是全状态数学证明。

- 48局原生CPU耗时探针最慢单步50.79ms；这不是最终Python提交的1秒时限验收。

## 五、决定与下一步

**不晋级，不替换保留对照，不打开O/P确认集。** 两种执行背景及所有失败组合都保留。没有任何配置满足八对手分别超过90%。

接下来应进一步核对“预测可兑现的生产/现金”与“实际调度和资金约束下兑现的生产/现金”，区分作物生命周期、投资时点、仓储丢失、供料/用工和成交后的计划变化。允许以实际偏差提出通用修正；不再扫描饲料权重、扩宽组合数量或从单seed最佳路线倒写规则。

已检查S3O/S3P记录：它们早已试过自身组合现金、双方收益差评分，未普遍晋级；不能把重新增加对手现金项当作全新突破。旧 `renew_ongoing` 也已有单独实验，若再测必须明确新增的因果组合依据，不能仅换名称重跑。
