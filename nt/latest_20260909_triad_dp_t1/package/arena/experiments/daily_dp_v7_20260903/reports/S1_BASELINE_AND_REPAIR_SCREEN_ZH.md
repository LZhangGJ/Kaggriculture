## 结论

1. 资源不足时不应丢弃整个已有维护组，确有可改收益；但改变产出、交易和后续投资也会改变竞争市场，因此不能按账面损失简单相加预测收益。
2. PASS小集超过18万不代表50局已通过；对G001全部仍为0胜，说明单修这些硬伤远远不够。
3. 同时保留现金与分差指标，不能因为对手也少赚了就宣称我方经营能力提升。
4. 保留全部独立消融及快照；下一步现金恢复、物流、竞争市场策略仍需整局验证。

## 本轮实现错误及纠正

第一轮expiry条件错误地把官方 `max_lifespan_step=-1`（未设腐坏时刻）当成到期。已加 `0 <= deadline`，增加局部测试，并重跑expiry/core。首轮这两组不用于上表或晋级，但原结果保留，不删失败证据。
