# S3W：投入时间审计与资金周转组合实验

2026-09-04。时间线审计、四组完整对照、新seed复验和现金/生产复盘全部完成。没有通用强度晋级，正式目标未达到。

## 1. 这次复盘改变了什么判断

不是普遍“买了种子/动物，却一直没有投入生产”。在A集900个已有条件的完整719步C++只读审计中，新增记录与旧版全部现金、生产、调度及溢出记录逐项一致。

共记录181,634个真实PLANT/PLACE批次，其中1,013批没有记录到主产品收获（0.56%，不是硬错误比例；可能是终局取舍、未成熟或其他原因）。种植/放置数、收取数、成交数量分别与独立生产账核对。种子和未放置动物的FIFO库存余额与最终真实库存核对。

例如对G003：

| 项目 | 购入后当天投入比例 | 首收相对名义首次可产出日 |
|---|---:|---:|
| 小麦 | 96.9% | +0天（按配置收获年龄4天） |
| 胡萝卜 | 95.8% | +0天（按配置3天） |
| 番茄 | 86.2% | 约+0.94天 |
| 草莓 | 92.0% | 约+2.24天 |
| 甜瓜 | 91.0% | +0天（按配置10天） |
| 鹅 | 100% | +0天 |
| 牛 | 99.0% | +0天 |
| 羊 | 98.8% | +0天 |

番茄/草莓有攒到较大批次再收的策略。这个等待不是“忘记收”，也不能不经比较就认定早点收更好。多数主产品首次收取后约下一天出现首次销售，符合日末自动回仓→次日市场处理。动物肥料可能更早变现，因此主产品等待不等于整个项目完全没有收入。小麦通常优先作为饲料，不能用首次出售晚来判定失误。

日初未开工目标依然存在，但其中很多根本没买到资源，另一些后来同格同类开工。不能把“同格以后出现同产业”写成承诺始终存在，也不能以同日目标全部完成作为经济最优标准。

## 2. 更实质的差距在现金与生产组合的时间关系

对G003的100局平均，零起算day=11结束，即第12天结束：

| 项目 | 我方 | 对方 |
|---|---:|---:|
| 累计销售收入 | 10,444 | 36,093 |
| 累计种子/动物/土地投资 | 10,015 | 14,737 |
| 当前现金 | 249 | 17,286 |
| 累计草莓种植 | 14.65 | 36.29 |
| 累计牛放置 | 6.78 | 8.46 |

对方不是仅靠少投资留下现金：它同期投资更多，而且已经收到更多收入。第20天结束我方累计收入59,291，对方79,925，差距有所追回但未消失。

这些是事实描述，不是“多种21棵草莓就能追回差距”的因果结论；价格、其他产业、初始组合、土地与人员投入都相互影响。它支持检查项目选择/融资周转，不支持继续把主要问题笼统归为买了不执行。

## 3. 新实验具体改什么

独立开关`capital_time_rank`。保持既有公共信息现金情景，累计项目每天尚未收回的投入，得到资金占用“元·天”；按当前剩余投资预算折算排序惩罚。预算充裕时接近原净收益排序，预算紧时更重视回款快的项目。计入动物肥料预计收入，不把主产品成熟日当作唯一回款日。

原净收益仍用于土地收益判断。这个排序只是新增项目的启发式，不是对未来精确模拟，也不是固定日期或产业数量。它不改变已有资产义务、底层工人操作、开局配置、官方规则或对手。已有资金日历mode2与它组成四组：

- old：原估值、原排序。
- calendar：仅既有按天现金估值。
- turnover：仅新增资金时间排序。
- calendar_turnover：二者组合。

未使用任何对手身份、隐藏库存或真实未来随机事件。原v6、以前开关和所有失败变体保留。

局限：占用时间来自条件现金日历，仍没有完整描述多人路径、具体仓储和销售顺序、未来工资增量或未见商店。可能错误偏爱占地便宜却收益低的产业。因此必须看真实终局现金和逐对手胜率，不能以资金周转指标变好自行晋级。

## 6. 复盘：不是程序没生效，而是代理指标偏了

以A集静止对手各100局为例：

| 指标 | old | turnover |
|---|---:|---:|
| 第12天结束累计收入 | 12,170 | 13,454 |
| 累计小麦种植 | 51.80 | 110.68 |
| 累计草莓种植 | 34.50 | 26.25 |
| 累计甜瓜种植 | 27.28 | 20.16 |
| 整季产品采购支出 | 15,138 | 9,827 |
| 整季工资 | 5,582 | 6,714 |
| 整季销售收入 | 215,719 | 196,236 |
| 终局现金 | 180,522 | 166,087 |

新排序确实让钱更早回流、少买饲料，但同时大量增加小麦循环、减少其他项目并增加人员支出，最终收入损失超过节省。不能把“更快回款/更少外购”当作最终赚钱目标。表格是整组处理后的账目变化，不声称每个产业数量差单独造成相应现金差。

对G003，组合在A集我方现金97,148→102,434，对手114,392→120,006；我方多赚仍可能扩大落后，实际胜率11%→6%。市场竞争下只提升自己的名义收益不足以提升胜率。

已审计发出操作无效果计数与动物逃跑均为0；不等于遗漏意图清零，也不等于已证明调度最优。本轮明确拒绝“提高资金周转就能解决根因”这个过强推断。

## 8. 保留与下一步

保留old为当前通用开发对照；四组配置及所有开关保留。calendar与calendar_turnover保留为不同优势的研究变体，但不得按真实对手身份自动切换。没有一个版本完成正式目标。

下一步不继续扫资金时间惩罚强度，也不强制指定小麦上限或草莓数量补救。先做**同一真实状态下，替换一组投资安排、执行后恢复同一基座的条件分支比较**：检查评分推荐和实际完整结果是否同向，并区分候选根本不强与排序选错。未来真实随机过程只能作为离线诊断标签，绝不能进入可提交策略。

如果有稳定强分支而评分选错，再将投入、所占地块、未来人工、主产品/副产品和出售连锁放进同一后果比较；不能再用“资金周转”“省工”“少缺料”其中一个代理指标代替终局现金与胜负。新的候选应能改变产业组合，而不只是像S3Q那样删减同一原始提案的前缀。这个方向尚未实现和验证，不承诺一定达到90%。
