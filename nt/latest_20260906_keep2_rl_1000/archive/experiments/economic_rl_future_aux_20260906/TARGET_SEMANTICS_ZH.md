# 预测目标的准确含义与边界

这份说明解释已冻结实现，不改变目标、损失、样本或选择规则。

|名称|已冻结全局特征索引|实际含义|不等于什么|
|---|---|---|---|
|cash|2|我方现金 / 100000|所有资产估值|
|margin|4|双方当前现金差 / 100000|终局胜率|
|standing_yield|72–80求和|场上当前挂着的产品数量 / 100|累计已生产、已收获或已卖出数量|
|water_due|82|当日尚未浇水的作物数量 / 25|每个都必须立即浇水，或精确维护动作成本|
|feed_due|83|当日尚未喂养的动物数量 / 25|每个都必须立即喂养，或饲料现金成本|

water_due / feed_due 是沿用原输入特征的维护负担代理，不是重新增加强制维护规则。特别是每个新日的记录会有日重置，因此这两个量可能主要体现生产规模，不能据预测好就宣称模型已经理解维护时机。

对每个当前日级决策，辅助头读取当前盘面和选中的候选，预测第1/3/7天后的上述值减去当前值。未到对应未来日的终局样本不参与该目标损失。所有目标都来自真实后续状态；对手仍实时行动。

该预测问题是“选这个，并由当前策略继续走，会发生什么”，不是“选这个，再自动采取最佳后续，会发生什么”。因此不能凭它修补候选里缺失的跨日合作或完整投资组合。

辅助头只接actor隐藏层，且只在训练时使用；C++权重仍只含原actor和critic。训练时目标来自未来是正常监督，不代表决策能读取未来。

完整步骤1的反事实标签与此不同：它比较候选相对KEEP的终盘胜负/分差，且后续交回原F3。两套标签的后续策略不同，不混合成一个所谓“客观真实价值”。
