# KEEP=2：从100轮完整状态续训至200轮

用户授权从100轮继续到200轮。本实验独立目录保存新证据，旧100轮目录只读，不覆盖旧权重/收据。不是重新初始化，也不是从各组开发最优轮数继续；四组均从各自step100的模型（包括辅助头）和Adam优化器状态恢复。

## 不变项

普通PPO/辅助预测PPO各两个配对重复；KEEP加分2，70,402参数actor/critic，辅助头1935参数、权重0或.1；10候选单项目F3 Overlay、账本、执行器、7个C++实时对手、官方规则、特征、奖励、每轮224局、4个epoch、512 mini-batch、lr3e-4、gamma1/lambda.95/clip.2/entropy.01均不变。没有追加阶段标签或扩大候选。C++16线程采样，RTX3090更新网络，顺序执行四组。

## 固定预算与数据隔离

- 每组执行第101–200轮，新增22,400局，累计44,800局。四组新增89,600局。
- 训练seed沿用原公式：69600000 + repeat*100000 + (round-1)*16，故新增区间为69601600–69603199和69701600–69703199，不复用前100轮seed。
- 每轮采样随机数仍为70000 + repeat*10000 + round；PPO洗牌仍为round + repeat*1000，保证连续训练定义不变。
- 继续使用69800000起32个固定开发seed（448局），评测120/140/160/180/200轮。保留旧0/20/40/60/80/100轮开发记录，以胜率、分差、同分更早轮数选模；不根据最终测试选模。
- 所有模型选择冻结后，使用70100000起100个全新最终seed。7对手×双座位，每配置1400局。
- 最终固定比较每组step100 greedy/sample、step200 greedy/sample、全历程开发选定greedy，加KEEP，共21项、29,400局。旧终测69900000起100seed不再作为本次终测。
- 总量只按训练局计数；开发和最终对战不进入训练。最终seed只用于这次验收，不根据结果补参数或换选择。

## 恢复与验收

1. 启动前核对旧完整目录manifest与源码hash；新模型导出必须与原step100.bin逐字节相同。
2. 确认Adam moment非零、已更新步数为5600，恢复前后参数及优化器一致；真实更新确实改变权重，继续后的优化器计数递增。
3. C++采样概率/logp/value与Torch一致，更新前ratio≈1；相同恢复状态的下一次更新可重复。只把预检用于工程验证，不把其对局混入训练。
4. 每轮保存输入权重sha、完整rollout、模型和优化器状态；检查719步、30个日级记录、高层mask及终局奖励。第29天只KEEP，不把它计为有效actor选择。
5. 完成后独立审计所有轮次、种子隔离、终测前选模、权重及优化器恢复；逐对手报告胜率、现金、分差、非KEEP、救回/破坏胜局、seed级配对区间和速度。

不预设200轮一定更强。结论区分训练量是否有帮助、是否优于KEEP、是否所有对手改善。只有两个训练重复；不做新模型的完整官方Python逐原子复验，不提交Kaggle、不推Git、不自动替换基座。
