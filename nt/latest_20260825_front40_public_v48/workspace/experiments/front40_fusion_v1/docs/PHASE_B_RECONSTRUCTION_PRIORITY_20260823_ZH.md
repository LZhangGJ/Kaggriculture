## 4. 对“精细复原”的严格定义

复原分四级，不能混淆：

1. **轨迹复现**：相同随机事件和相同对手动作流时，动作、状态、终局现金逐步一致。
2. **自由滚动复现**：换新随机事件后仍能完成719步，且赚钱分布、产业里程碑和失败长尾接近原玩家。
3. **条件策略复现**：不同商店、市场和对手盘面下，分支方向和触发时点与 Replay 统计一致。
4. **对战能力复现**：双座位对局中，能在独立强敌池保持稳定竞争力。

只有达到第3级，才可称为“前排策略 Agent”；只达到第1级的版本只能叫 Replay 轨迹代理。

## 5. 实现原则

- 原子动作序列可以作为事务顺序和多人协同的教师，但不能直接成为正式融合策略的唯一决策来源。
- 每个完整 Agent 都使用同一个可见状态接口；禁止作者名和路线来源路由。
- 商店路线应采用“基础承诺 + 增量投资/减量维护”，不能在中途冷切到另一条未同步的 Replay 程序。
- 对手响应只允许读取官方公开盘面，并必须通过真实对手特征相对打乱特征的留出提升证明有用。
- 后期模块以第600步真实状态为起点做同状态反事实续跑，用最终胜负、分差和执行失败率决定是否采用。
- 一个能力若只改善来源玩家，却伤害其他路线家族，就保留为独立对手代理，不进入融合 Agent。
