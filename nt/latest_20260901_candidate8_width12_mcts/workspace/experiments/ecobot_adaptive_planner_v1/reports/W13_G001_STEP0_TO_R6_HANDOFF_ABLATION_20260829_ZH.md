# W13：G001 第一步后交回 R6 消融实验

日期：2026-08-29

## 1. 实验问题

验证下面这个最小改动是否能够修复 R6 对 G001 的早期偏离：

```text
第 0 步：完整执行原生 G001 的单位动作和有序市场事务
官方/C++规则结算共享市场
第 1～718 步：从结算后的真实状态开始运行原生 R6 动态规划器
```

本实验不是播放 G001 整条路线，也没有把 G001 身份输入 R6。

## 2. 实现与动作一致性

C++ `NativeAdaptiveExecutor::play_blend` 新增离线诊断模式 6。模式 6 在第 0 步不调用 R6，避免 R6 为一个实际没有执行的动作错误更新持久计划；第 1 步才从真实结算状态初始化 R6。

动作级验收使用 8 个随机种子、双座位共 16 个状态：

| 验收项 | 结果 |
|---|---:|
| 候选方第 0 步与原生 G001 完全一致 | 16/16 |
| 对手第 0 步与原生 G001 完全一致 | 16/16 |
| 完整执行 719 步 | 16/16 |
| 第 1 步已经交回 R6，并与 G001 不同 | 16/16 |

动作一致性验收通过。

## 3. 正式对照

对手固定为 G001，随机种子 `2843001..2843128`，双座位，共 256 个配对状态。每个状态比较：

- 基准：纯 R6；
- 实验：G001 第 0 步 → R6。

| 指标 | 纯 R6 | G001 第一步→R6 | 变化 |
|---|---:|---:|---:|
| 对局数 | 256 | 256 | — |
| 我方平均终局现金 | 64,320 | 62,970 | **-1,350** |
| 我方 P10 现金 | 37,407 | 39,744 | +2,337 |
| 对手平均现金 | 107,162 | 105,624 | -1,538 |
| 平均分差 | -42,841 | -42,654 | +188 |
| 得分率 | 2.34% | 2.73% | +0.39个百分点 |
| 胜局 | 6 | 7 | +1 |
| 作物硬损失 | 0 | 0 | 0 |
| 动物硬损失 | 0 | 0 | 0 |
| 仓库溢出 | 0 | 0 | 0 |

配对结果：

- 119/256 局我方现金提高；
- 137/256 局我方现金降低；
- 现金变化中位数为 `-2,478`；
- 从非胜变成胜局 7 局，同时从胜局退化为非胜局 6 局；
- 两个座位的我方平均现金都下降，说明不是单一座位偏差。

## 4. 结论

**“只播放 G001 第一步”不能修复 R6。该假设在本轮被否决。**

G001 的第一步不是一个可以孤立移植的免费增益。它建立的小麦、种子、羊和雇工组合需要后续连续的多人任务链、布局和事务节奏共同兑现。R6 在第 1 步立即按自己的价值模型重新规划，没有继续兑现这套开局承诺，因此平均终局现金反而下降。

平均分差略有改善，是因为我方第 0 步改变了共享市场，也使 G001 对手平均少赚约 1,538；这不代表我方经营能力变强。

因此，先前观察到的第 0 步分歧是真实的，但它只是整套执行差异的起点，不是全部原因。下一项更有信息量的实验应当比较 G001 前缀长度 `1/2/4/8/24` 步后再交回 R6，找出完整开局任务链开始产生可兑现价值的最短前缀；不能把 G001 第一步直接并入正式 Agent。
