# W3：以 Rank1 最新 Submission 55714246 为主的阶段报告

日期：2026-08-28  
状态：阶段能力验证通过；最终 Agent 未验收，尚未达到对 G001 90% 胜率。

## 1. 证据口径

- 主证据：Crop Dusta 最新 submission `55714246` 的 151 场公开 Replay。
- 旧 submission：只用于判断长期稳定能力，不作为当前路线目标。
- 最终 Planner 不读取作者、Replay ID 或对手身份。
- 只迁移公开状态可解释的能力：经营日历、未来布局承诺、商店机会和市场周期。

## 2. 已确认的最新路线能力

1. 开局先保持约 3 牛、2 羊和小麦/草莓/甜瓜混合生产。
2. 第 5–9 天根据 YARN_STORE/羊毛市场，形成羊重或牛/混合分支。
3. 第 19–24 天存在胡萝卜或小麦终盘后缀；直接移植胡萝卜分支会退化，暂不启用。
4. 最新路线会从开局为未来动物结构保留仓库周边物流区，作物主要铺在外圈。
5. 小麦市场存在按官方城镇消费周期运行的现金循环，但简单启用大仓位会造成容量和市场冲击，暂不纳入主候选。

## 3. 本轮修复

### 3.1 确定性执行修复

- 第 30 天不再为未来喂养保留小麦。
- 第 30 天清仓后不再重新买入饲料，消除必亏的反复买卖。
- 修复建筑预留列表含杂草时错误跳过无关可种地块的问题。
- 修复单局 trace 工具未读取 genome `base_values`、导致诊断结果与批量 Arena 不一致的问题。

### 3.2 新增通用可搜索能力

- `future_structure_reservation_fraction`：按照已选 30 天动物承诺，预留未来牧场/鸡舍空间，不使用固定坐标。
- `yarn_animal_flex`：仅释放尚未购入的可逆牛/鹅承诺；已经买入的动物不可逆。
- `yarn_opponent_sheep_gate`：已实现为实验参数，但当前证据不足，未进入主候选。
- 小麦现金循环改为按官方 4 步消费周期分批买入、消费后卖出；当前仍是实验能力。

## 4. 关键结果

### 4.1 未来动物布局预留

`future_structure_reservation_fraction=0.75` 在独立 512 seeds、双座位测试中：

- 对 G001：我方平均现金 `65,166 -> 67,210`；平均分差改善 `1,645`。
- 对静止对手：`119,475 -> 121,346`。
- 最新来源 seed：`85,228 -> 101,602`。

同一来源局中，牛群到仓库平均距离从约 `2.82` 降到 `1.36`；Rank1 原路线约为 `1.60`。

### 4.2 布局 + YARN 动物分支

独立 512 seeds、双座位：

- 对 G001：我方平均现金 `65,166 -> 70,554`；分差改善约 `2,920`。
- 对静止对手：`119,475 -> 121,802`。
- 静止对手 P10：`84,947 -> 92,584`。

在 9 个不同产业对手上，组合方案：

- 9/9 提高我方平均现金；
- 8/9 提高平均分差；
- 平均现金增加约 `4,791`；
- 平均分差改善约 `3,301`。

唯一分差退化的是羊重路线 G267。单独消融表明：布局本身对 G267 有利，退化来自羊分支在重羊竞争下过度投入。因此当前应将“布局预留”视为已通过的通用核心，将羊分支视为攻击型候选，继续做跨对手门控，而不是直接冻结为最终冠军。
