## 4. 已冻结实施边界

1. 默认主线必须是 G001；
2. Challenger 必须写清楚“G001 + 哪个局部修改”；
3. 其他完整路线只能作为反事实后缀、能力供体或对手；
4. 多个候选联合覆盖不能冒充单个 Agent 对全Arena达到90%；
5. C++负责高速筛选，JAX抽查，官方Python负责最终裁判；
6. 每项改动保留开关，失败时可以回退纯G001。
