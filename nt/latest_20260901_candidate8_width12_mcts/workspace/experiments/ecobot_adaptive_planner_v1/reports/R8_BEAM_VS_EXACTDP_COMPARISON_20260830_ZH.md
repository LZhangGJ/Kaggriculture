# R8 Beam 与 Exact-DP 对比

日期：2026-08-30  
规则：官方 `kaggle-environments==1.32.7`  
结论：**现阶段应优先使用 R8 Beam；Exact-DP 没有表现出足以抵消约 4 倍吞吐损失的稳定收益优势。**

## 1. 比较口径

旧 Beam 已由当前源码中的 Exact-DP 替换，因此本次使用冻结的 Beam 收据，并让当前 Exact-DP 重新运行完全相同的 seed、座位、对手和高层计划。

- Beam：逐层保留少量最优任务序列，提前淘汰低分分支。
- Exact-DP：在每单位最多 8 个候选内，枚举所有合法任务子集和顺序状态。
- 两者都只改善 R6 已选择任务的低层执行，不能补充新的经营项目或改变高层经济路线。

这能公平比较确定性对局结果。吞吐对比使用同一批 1,000 局正序/逆序专用测试；但由于 Beam 和 Exact-DP 来自前后两个源码版本，速度比代表两个完整实现的实际差异，不是只隔离一行算法开关的微基准。

## 3. 吞吐与延迟

同一批 1,000 局 PASSIVE、双顺序隔离测试：

| 指标 | Beam | Exact-DP | Beam 优势 |
|---|---:|---:|---:|
| 正序吞吐 | 97.33 局/s | 24.47 局/s | 3.98 倍 |
| 逆序吞吐 | 97.62 局/s | 24.56 局/s | 3.98 倍 |
| 单局 P50 | 106.97 ms | 496.88 ms | 4.64 倍 |
| 单局 P95 | 113.00 ms | 520.97 ms | 4.61 倍 |
| 每环境步 P95 | 157.16 us | 724.57 us | 4.61 倍 |
| 跨局污染 | 0 | 0 | 相同 |
| 硬错误 | 0 | 0 | 相同 |

按专用吞吐估算：

| 模拟量 | Beam | Exact-DP |
|---|---:|---:|
| 10,000 局 | 约 1.7 分钟 | 约 6.8 分钟 |
| 1,000,000 局 | 约 2.85 小时 | 约 11.3 小时 |

两者都远低于线上每步 1 秒限制，但离线搜索和反事实数据生成中，Beam 的计算优势非常明显。

## 4. 结论与使用建议

1. **默认低层执行器改回 Beam 更合理。** 它快约 4 倍，而三组同 seed 对照没有显示 Exact-DP 的稳定实战优势。
2. **大规模搜索、反事实标签和 Self-play 使用 Beam。** 同样时间可覆盖约 4 倍局面，综合学习效率更高。
3. **Exact-DP 暂时只保留为诊断或少量决赛候选复核工具。** 只有未来证明某类高冲突任务上能稳定改善分差，才考虑按条件触发。
4. 当前主要短板仍是高层计划表达：投资时点、布局、人员任务链、同回合市场顺序和条件分支。把计算继续花在低层精确枚举，不能补回对 G001 约三万元的路线差距。
