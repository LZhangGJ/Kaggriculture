# G001 与 Candidate8 共用 Day0 的同局获胜路线对照

## 1. 结论

本实验成功构造了一个严格的同局对照：

- 同一个强路线对手：`G012 / fufufukakaka / route_id 97605511:1`；
- 同一个随机种子：`3041006`；
- 同一个座位：我方 `seat 0`；
- 前 24 个 transition 完整播放 G001，双方联合动作逐项完全相同；
- 从 Day1 开始，G001 继续原完整拳法，Candidate8 则进行七节点事后搜索；
- 两条动作流均为 719 步，并通过官方 `kaggle-environments 1.32.7` 逐步重放，官方终局资金与 C++ 完全一致。

结果：

| 路线 | 我方终局现金 | 对手终局现金 | 分差 | 结果 |
|---|---:|---:|---:|---|
| G001 完整拳法 | 123,940 | 67,818 | +56,122 | 大胜 |
| Candidate8：G001 Day0 + 事后最优后续 | 93,016 | 59,890 | +33,126 | 大胜 |

两者都能明显击败同一高手路线，但胜法不同：

- **G001 靠自身高吞吐生产取胜**：更早、更集中地建立牛奶与草莓复利链，少雇人却完成更多有效动作。
- **Candidate8 靠较保守的混合经营加对手状态扰动取胜**：自身赚钱能力明显弱于 G001，但使对手最终少赚 7,928，仍取得 33,126 的优势。

最重要的负面结论是：**Candidate8 的候选语言已经能找出一条明显取胜路线，但其执行效率和生产链强度仍远未达到 G001。** 事后 Oracle 获胜不等于已经复现高手拳法。

Candidate8 使用的是事后 exact-future Oracle：在七个决策日分别比较候选继续打到终局后的真实胜负和分差。这符合本次“事后寻找”的要求，但不能作为线上可实现能力宣称。

决策日为：

`Day 1 → 3 → 6 → 9 → 12 → 18 → 24`

搜索配置：

- beam width：32；
- 每节点候选：64；
- 完整终局续跑：11,774 条；
- C++ 搜索时间：12.36 秒；

这里“同一对手”指同一冻结的 G012 路线执行器。双方盘面被我方不同动作改变后，该对手会基于真实状态执行、失败或偏移，所以 Day7 之后它的实际动作流可以不同；这才是合法对战，不是强行播放与状态不符的原始动作。

## 5. G001 为什么赢

### 5.1 核心思想：集中复利，而不是平均分配

G001 没有把所有产业平均铺开，而是把 Day0 的羊和甜瓜作为启动现金链，随后快速放大：

`小麦饲料 → 牛 → 牛奶 + 肥料 → 草莓高产区 → 更大现金流`

Day6、Day9、Day12 的牛数量分别达到 `6、9、11`；草莓规模达到 `11、21、40`。这是一条明确的“高维护、高吞吐、高复利”路线。

### 5.2 人员少一些，但每个动作更有效

全局动作统计：

| 指标 | G001 | Candidate8 | G001优势 |
|---|---:|---:|---:|
| HIRE总量 | 282 | 297 | 少雇15人 |
| PASS | 421 | 1,334 | 少913次空转 |
| PLANT | 206 | 117 | 多89次 |
| WATER | 986 | 605 | 多381次 |
| HARVEST | 420 | 251 | 多169次 |
| 四方向移动合计 | 3,507 | 3,748 | 少241次移动 |

这说明 G001 的优势不是简单“雇更多人”，而是**单位任务链、布局和移动编排更紧凑**。它用更少的雇工和移动完成了显著更多的种植、浇水和收获。

### 5.3 产销规模远高于 Candidate8

G001 卖出：

- 草莓 433；
- 牛奶 335；
- 小麦 326；
- 羊毛 179；
- 肥料 400；
- 另有甜瓜和胡萝卜。

Candidate8 对应只卖出草莓58、牛奶174、小麦138、羊毛135、肥料202。G001 的优势从 Day13 后迅速扩大，说明其前半局投资已经形成现金复利，而不是靠最后一次抢卖偶然取胜。

### 5.4 终局转换更完整

G001 在后半局逐渐减少长周期项目，Day24 已转向41块小麦，并把 shed 和种子全部变现。Candidate8 虽然也清空 shed，但终局仍有未兑现作物和种子，说明其停止投资、收割和清仓链仍不够精确。

## 6. Candidate8 为什么也能大胜

### 6.1 核心思想：连续重平衡，而不是死守一条产业线

Candidate8 七次选择依次为：

`REBALANCE → REBALANCE → REBALANCE → CAPACITY → REBALANCE → CAPACITY → SCALE`

实际表现为：

- Day1 先扩人员容量；
- 不跟随 G001 立即重押草莓；
- 牛只扩到8头，保留4羊；
- 同时经营小麦、胡萝卜、番茄、草莓和甜瓜；
- 根据后续真实结果继续修改规模和容量。

它的路线更像“多产业分散风险 + 不断纠偏”，而不是 G001 的集中复利拳法。

### 6.2 它没有赚得比 G001 多，但改变了对手的兑现结果

同一 G012 对手在两局中的终局现金：

- 面对 G001：67,818；
- 面对 Candidate8：59,890；
- 少赚：7,928。

对手在两局的第一次经济状态差异发生于 transition 33，仅差1现金；第一次实际动作分歧发生于 transition 170；第一次牛数量分歧发生于 transition 263，随后对手牛规模从原本12头落到8头。

因此 Candidate8 的33,126分差由两部分组成：

1. 自己仍完成了93,016的中等强度混合经营；
2. 不同的市场与现金链让同一对手后续动物扩张和执行结果变差。

审计能确认这条因果链的发生顺序，但**不能仅凭这一局证明 Candidate8 有意识地设计了“卡掉对手4头牛”**。更严谨的说法是：这是被事后 Oracle 选中的有效市场外部性，而不是已经学会的线上战术。

## 7. 两种拳法的本质差异

| 维度 | G001 | Candidate8 事后路线 |
|---|---|---|
| 经营骨架 | 牛奶+草莓的集中复利 | 8牛4羊+多作物分散 |
| 资本使用 | 尽早把钱转成高产资产 | 更重现金缓冲和逐段修正 |
| 人员策略 | 少雇但高利用率 | 更早扩员，但空转较多 |
| 空间执行 | 移动更少、有效动作更多 | 移动更多、生产兑现较弱 |
| 市场效果 | 主要靠自己产量碾压 | 自身中等收益，并扰动对手现金/动物链 |
| 终局 | 转小麦并较完整清仓 | shed清空，但地图和种子仍有残余 |
| 可在线性 | 完整固定拳法可直接执行 | 当前选择来自真实未来，只代表表达上限 |

一句话概括：

- **G001：先构造一台高效率赚钱机器，再让它连续复利。**
- **Candidate8：不断换参数寻找能赢当前对手的经营组合，但底层机器本身还不够高效。**

## 8. 对后续开发的直接启示

这次实验说明短板不能再笼统归为“Candidate8候选不够多”。七节点候选已经能找出明显获胜路线，但仍比 G001 少赚30,924。差距主要来自：

1. 候选只修改宏观规模，无法直接生成 G001 那样精确的日内生产链；
2. 低层人员利用率低，出现913次额外 PASS 和241次额外移动；
3. 高收益产业的投产速度不够快，Day12 只有8牛和6草莓，而 G001 已有11牛和40草莓；
4. 后半局停止投资与清仓不完整。

因此下一步最有价值的不是继续把64个候选扩成几百个，而是把候选从“目标数量修改”升级为可以提交并验证的完整项目包：

`产业增量 + 投产日 + 所需人员曲线 + 地块布局 + 前置交易 + 24步任务链 + 清仓日期`

然后再用相同的终局续跑选择项目包。这样 Candidate8 才可能同时拥有“动态选择能力”和“G001级别的生产兑现能力”。
