# S3X：Day 0 候选可识别性审计

## 为什么必须做

Day 0 时不同 seed 和对手身份尚未从公开盘面出现。虽然事后可以为每局挑一个获胜候选，线上 Agent 实际只能对相同公开状态作出同一个选择。

900 局的 Day 0 候选集合完全一致，共 68 个；现有解析评分在 900 局中也始终选择同一个候选。

## 身份不可见时的固定 Day 0 结果

| 选择法 | 候选 | 八对手平均胜率 | 最弱对手胜率 | PASS平均现金 | 八对手平均分差 |
|---|---|---:|---:|---:|---:|
| 当前 KEEP | KEEP / -1 / 0 | 32.9% | 11.0% | 180,522 | -3,014 |
| 当前解析评分 | EXPAND_NEW / 10 / 4 | 20.8% | 2.0% | 173,464 | -8,174 |
| 最大化最弱对手 | REPLACE_NEW / 3 / 1 | 55.2% | 22.0% | 178,186 | +7,019 |
| 最大化八对手平均 | REPLACE_NEW / 3 / 1 | 55.2% | 22.0% | 178,186 | +7,019 |
| 最大化 PASS 现金 | EXPAND_NEW / 11 / 4 | 24.4% | 4.0% | 186,120 | -5,868 |

## 结论

- 每局事后 100% 左右的翻盘覆盖，只证明候选里存在好改法，不能证明线上能够识别。
- Day 0 必须采用身份不可见的稳健开局；只有看到公开盘面变化后，动态选择器才有条件分流。
- 若最稳健固定候选仍明显低于目标，下一步应把模拟后果估计用于 Day 1 之后的可观察分流，而不是用真实 seed 为 Day 0 贴标签。

本审计未使用最终保留集，不是可提交策略，v7 总目标尚未完成。
