# S4G：开放自主开局的实验失败，不晋级

## 结论

已解除“第0天一定播放配置开局”的限制，但现有经济选择器生成了更差的完整路线。不是动作没生成，也不是只看单seed；7200条实时配置对局和5400局只读重复对账已经完成。`autonomous_start` 保留但默认关闭，八对手目标未完成。

## 改动是否真的执行

唯一新增运行代码是独立开关，让初始状态进入已有日常投资选择器。未修改原子规则、对手或未来随机过程。机理测试覆盖忽略旧opening参数、现金预算、产业上限、禁用动物后的作物选择、日1以后原选择逻辑不变。

800个初始状态检查（8配置×50seed×2座位）显示相同可见开局下结果完全相同：

- 固定控制提出2牛、1羊、2鹅、6草莓、4小麦。
- 自主原评分提出6牛、1鹅、1胡萝卜。
- 自主＋既有日历评分提出3牛、3羊、2小麦。

这些是评分自然生成的目标，不是写入的数量。初始提议、市场意图不等同于成交/完成；后续真实日0账目也确认相应种植和放置已经执行。相关收据 `receipts/s4g1_initial_plan_v1/summary.json`。

## 真正的现金链证据

以复杂组合对G003的100局为例，相对固定控制：

- 总销售少9282元。
- 饲料等采购多4860元，几乎都是小麦采购：6633→11503元。
- 工资反而少505元。不能把本次退化归于多雇人。
- 牛奶售出约196.94→235.33单位，但牛奶销售23759→17167元。更多产量没有形成更多收入；实际成交时点及双方市场影响都在变化，不能将全部差额单独归于我方压价。
- 小麦实际产量414.86→265.42；鸡蛋产量123.60→61.10；草莓产量约204基本不变，但销售额32855→29363。产品结构、供料依赖、售价时点必须共同考虑。

**反对过度归因的重要结果：** 自主版第12天累计销售15524元，高于固定版11134元，日末现金也更高，但终局反而明显变差。因此“S4F看见早期少卖货→只需加快早期现金”并不成立。必须同时比较早期回款与后期市场/维护后果。

## 仍缺什么，不能靠什么替代

1. `values` 的默认全季边际排序不是经过执行验证的组合盈利模型；仅开放更多选择不会自动变强。
2. `funded_bundle_mode=2` 主要从已选新项目里删减并检查当日融资/排班，不会重新联合优化所有产业组合或保证未来每日现金足够。
3. 既有日历估值能缓解部分退化，但不能复现真实采收/入库/出售节奏；它还按参数决定是否扣除已有动物的后续喂养需求。不能把它称作完整因果经济规划器。
4. 当步合法、能开工、不逃跑，都不是“值得投资”的充分条件。本次重复审计无效果动作和非计划逃跑为0，但实力仍弱。

下一步优先检验“自主选择与已有动物未来饲料估值”的组合缺口，而不是手工改回几头牛或几个瓜。S3J等旧研究单独试过饲料权重，没有普遍晋级；本次必须明示这是与新自主开局/现金日历的交叉测试，不声称发现了从未见过的问题。若仍失败，不继续扫饲料倍数，应转向可执行完整组合的后果估计。
