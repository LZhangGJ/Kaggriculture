# S4K2：修正新资源保护对终局销售的误删

S4K 的7200场配置已经全部完成，尚无晋级。真实账本发现不是原先猜测的“新增维护挤掉生产”为主：对PASS旧对照产出牛奶293.58、羊毛122.98；S4K恢复版完全相同，但少售出牛奶14.23、羊毛6.32、草莓17.69，最终现金180428→170715，终局随身/仓库商品显著增加。

代码证据：旧 `market` 允许终局当前 DROP 的商品纳入 SELL；新增 `service::protect` 对所有商品都按照动作前库存截单，漏掉同回合 DROP 入库。即使某商品完全没有任务预留，也受到影响。这是本次实现引入的错误，不是反证动态恢复没有价值。

## 唯一修正

资源保护仅限制有实际未完成 PICKUP 预留的商品；没有预留的商品必须保持原市场订单不变，包括 DROP→SELL。不修改经营参数、开局、调度排序、数量或对手条件。

新增专项回归先在坏版本证明失败，再在修正后通过：终局仓库为空、单位携带牛奶、当前DROP与SELL；已有小麦预留不应删除无关牛奶出售；原小麦保护继续生效；关闭开关保持原状。

## 冻结复验

原封不动使用S4K八配置、N50×双座位×九对手/PASS=7200场；六个改动配置5400场重新实物与现金闭合审计。旧S4K失败源码和原结果不覆盖、不删除。旧23项、4490项机制及新回归、32官方样本均须通过。

本次仅修一个明确的事务语义回归，不按照某个seed或胜率改策略。先修完再判断恢复/采购能力的真实经济价值；O/P不动。最终目标没有降低。
