# S3Q：投资包更可执行，但未转化为全面高胜率

2026-09-03。已完成本轮开发与验证；不替换保留基线，goal未完成。

## 1. 改动不是再扫收益权重

保留原完整经营提案作为KEEP。新增可开关的投资包比较：

当前提案的不同新增规模 → 采购/卖货融资/雇工 → 顺序成交条件投影 → 材料预留 → 现有多人排班 → 对能开工的项目评分。

未供料或排不进去的新项目不再得到全部预期收益。不使用的新土地可不立即购买。保留原提案已经能安排的既有资产操作，实际成交之后仍按真实状态编排。不改官方1.32.7、开局来源、对手代码；不输入身份、隐藏库存或真实未来。

枚举的是当前新增提案的不同规模前缀，不是全部产业组合，也不是完整跨天联合规划。所谓撤回/延期，只是本日不执行该目标，**没有承诺明天一定恢复**。这点不能包装成已实现持久投资日历。

模式0保留原行为；模式1只在原提案有新项目不能兑现时介入；模式2在所有有新项目的日初比较。没有据比赛结果拟合新阈值。

生产结构也变了。例如A批对G001累计种植：小麦86.80→80.66、胡萝卜41.31→50.59、草莓25.88→25.05；牛放置8.68→8.15。不是单纯省了503元工资，其余生产完全不变。不能把任一现金账差额直接当成可独立追回的收益。

在本次审计覆盖的已发出操作中，无效果计数仍为0；这不证明所有过滤前意图正确，不证明调度最优，更不证明不存在经济机会损失。

## 4. 确定结论与不能下的结论

确定：局部融资/供料/排程可行性改善，仍不足以实现全对手90%。这轮策略不应默认启用。

不能说：对手信息无用、低层没有问题、所有收益差都来自开局、只要再加一个阈值就能解决。

代码可确认的剩余缺口：

1. 只给当天能开工的新项目计值，缺少“今天买、明天放置/补种”的跨天承诺价值；不能证明这些延期投资一定差。
2. 工资/资金约束改了，但长期产量和售价仍来自原近似公式，未对真实现金兑现时间做完整校准。
3. 候选只缩放原提案，不能充分改变产业结构、投资顺序、未来雇工与维护安排。
4. 排班仍沿用日内Job块和启发式匹配，没有新增跨工人任务块接力或全局滚动重排。

这些是明确的能力边界，不是由本轮数据唯一证明的失败根因。
