# S4Q：加入经营后果选择，没有整体突破，不晋级

2026-09-04。本轮为 progress：正式加入两个独立开关，完成机制、官方一致性、5400场实时对照、3600场重复账本和64场逐步选择审计。八对手逐一>90%的Goal未完成，继续active。

## 1. 证据与实际改动

S4P证明仅用日末现金或仓库清仓报价不足以比较排程，且共享排程会改变日内新增生产。因此本轮不是增加固定日期、作物数量或对手路由，而是加入：

- `day_consequence_compare`：在真实观察中，比较修复后保留安排和原协调器提出的新安排。只在两者确实不同且非最后一天时运行。
- `day_value_public_supply`：在上述剩余经营估值中加入对手公开产能压力；可单独关闭。不读取对手隐藏仓库、实际未来动作或真实随机种子。

两套安排均用当前观察重建的原C++规则情景执行到当天结束，对手在该条件情景中PASS，未知新杂草/商店不读取真实未来。预演关闭后续联合改派以保留干预，其余生产、市场、失败恢复保留。随后估算已有作物/动物的剩余产品、种子、饲料/肥料及共同用工成本。已有种子抵扣后续买种，动物不可当可卖资产，饲料不能先全卖再虚构买回。

预测的是**维持当前项目、同作物续种**的条件价值，不是完整最优未来；未知劳力/融资情况退回原启发式选择。新选择器可以否决原重排，但不新增非法动作，也不把预测当官方合法性规则。两开关默认关，源码和六配置在`profiles/s4q`冻结。

## 4. 64场实际选择审计

固定`all_intraday_insert_value`，八对手各4个已有开发seed、双座位，共64场原样实时重跑；双方终局现金逐场与面板一致。诊断只操作Controller副本和公开观察情景，不改变实际动作或读取真实未来继续选方案。

- 全部1994次真实比较被诊断捕获，并逐次核对真实选择器计数；554次否决原重排，未知回退0次。
- 418次两个候选的日末生产规模不同。对最终选中的安排，实际日末规模与条件预测不同21次，即1973次相同。
- 各对手检查点的日末现金平均绝对误差约3.9–51.7。窗口重叠，不能把1994次当1994个独立样本，也不能相加差额。
- 六日对手的62次否决中，新重排平均预计少0.81个在田项目，剩余估值低436，其中未来交易收入低518、工资少29、种子少25。其他对手也常有类似“少一个在田项目→剩余估值下降”的情况。

一个机制例子：某真实开发状态day5/hour9，保留安排日末8格小麦、现金2；重排7格小麦、现金12，其余记录的产业规模、仓库和市场相同。估值却分别80615和79679，因此保护了多种的一格。**这只证明选择理由，不证明此处少种必然更优**，也不准把该seed或固定数量写入运行策略。

据此可以排除“开关从未执行”“当天规模普遍预测错误”作为主要解释；不能据此证明长期估值误差是全部败因。尚未比较每个被拒绝安排的真实终局后果，本轮没有恢复事后Oracle。

## 5. 新暴露的估值边界

源码`day_consequence.hpp::work_calendar/residual`只给当前在田资产估价，并假定同作物后续续种；没有给空出来的地块、现金和人力寻找后续替代项目，也没有在下一天重新运行完整经济规划后再评估。因此：

1. 多种一格可能被计入剩余全季的续种收益，而少种暂缓得到的现金和未来换产机会没有对等计价。
2. 收获后暂空的地块与项目真正取消还未在估值层充分区分；不能因此推导“收获就亏”。这需要专门受控测试，尚未认定为本轮某场败局的原因。
3. 未来日历按条件充足材料生成，融资只检查按日汇总，未来日内现金/市场顺序并非全部精确；联合用工仍是近似打包。
4. 对手公开产能只是条件供给量，不是可靠的出售日期预测。本日预演对手PASS也会留下市场误差。

**优先待检验假设**是跨日估值把短暂生产差放大为永久经营差，忽略下一日可恢复和替代投资；不是已经证明“只要补某个特征就上分”。下一轮先用真实日志核对下一日任务、目标及资源变化，并构造“收获后继续种/暂缓再种/真正停止”的受控案例。只有预测偏差可重复、修正不引入先验固定策略时再接独立开关。不得扫一个任意劳动/现金权重来掩盖结构缺口。

## 6. 四项能力的实际边界

- 多人协同：无材料服务任务可跨工人、沿途插入；带材料任务仍有限制，非任意任务全局最优。
- 每步协调：真实状态修复＋局部重排已运行；不是所有项目与所有工人组合穷举。
- 采购生产并行：沿用已验证准备阶段并行、资源保护、成交回写；本轮没有宣称新增完整融资规划。
- 比较经营后果：本轮首次在该重协调入口正式比较两个日内安排及剩余价值，但长期价值不够可靠，未晋级。并未完成任意多套编排的完整经营后果求优。
