# S4X：现有策略的成熟产品与出售预测只读审计

2026-09-04。目标是检查胜率缺口的机制，不改生产策略，不启动事后选拳。

## 冻结范围

- 使用 S4V 同一正式 C++ 构建与原八个实时对手；不重新下载或替换对手。
- 两个已有背景：`all_intraday_insert`、`full_chain_autonomous`。
- 已使用的开发 seed 20262701、20262702，双座位，共 64 完整局。这是机制筛查，不是新的独立强度验收。
- 只读探针核对控制器状态未修改，完整局双方现金必须逐局等于已有面板。

## 记录

1. 当前可收产品是否进入生成任务、剩余计划或本步已发出的 HARVEST。
2. 未进入计划的产品数量、产品类型、到收获和仓边 DROP 的乐观移动下界。下界未扣除原任务、资源和仓容，不能据此声称机会可兑现。
3. 原 `competition_sales` 的预测库存和真实建议必须一致。
4. 事后检查原预测时点后的实际库存，并单列本方已成交买卖的直接库存贡献。只用于评价历史预测，不把真实未来提供给决策。

同一产品跨多步观察不能累计成许多份新收入。库存误差不能直接等同可获得的反事实利润；剔除本方订单也不能剔除对手的反应。

## 决策边界

本轮不提供新增策略胜率。先确认误差和潜在遗漏的分布；若发现广泛证据，再设计收获—物流—部分出售联动候选并做开关实验。不能因为几个案例就写死作物规模或日期。

S4W 任务替换隔离原型的第二版机制测试失败于“临终未成熟动物应不值得维护”的断言。需要核实肥料等副产物和实际评分，尚不能判定为真实调度错误；不接入正式 Agent。
