# S4A：四项执行能力收敛与组合验证预注册

日期：2026-09-04。状态：执行前冻结。范围仅限本地自主动态规划器与底层执行器；不提交、不训练、不推 Git。

## 1. 目标与明确边界

本轮根据真实败局、官方机制和既有多 seed 对照，逐项补齐四项通用能力：

1. `shared_task_atoms_v2`：同一地块的可交换子任务允许不同工人接力，真正存在前置依赖的建立链仍保持有序。
2. `stepwise_recoordination`：每一步读取实际位置、实际库存、已完成效果和 deadline；只保留仍合法且仍有价值的局部安排，其余工作重新分配。
3. `preparation_pipeline_v2`：采购/融资期间，已有工人继续完成不依赖未成交资源的生产；成交不足后按实际状态重编译，而不是按投影继续。
4. `schedule_value_compare`：保留原排班，同时生成多套合法人员编排；以预计可兑现现金、必要任务完成率、终局/日末物流损失和工资为后果比较，不以最短路单指标决定。

禁止：Candidate 事后 Oracle、真实未来事件、隐藏对手库存、对手身份路由、Replay 日历播放、固定 seed/固定商品数量补丁，以及把某个 seed 的事后最优候选写进运行策略。

## 2. 已有能力审计，避免重复开发

| 需求 | 已有实现及证据 | 当前缺口 | 本轮处理 |
|---|---|---|---|
| 多人协同同一地块 | `split_service_jobs` 可拆存量作物/动物的独立维护；A+B+I 共10,800局，确实改变分配 | 新项目链不拆；携带物交接、逐步改派未完成；收益不稳定 | 旧开关作为对照，V2必须和逐步重协调共同工作 |
| 每步重协调 | 每个动作发出前有合法性检查；少数恢复分支会重编译 | 日内路线通常只在采购结束后编译一次；失效动作多为跳过，未统一释放/改派 | 首个实现重点 |
| 采购与生产并行 | `preparation_work` 允许脚下、队首、无物料的少数动作 | 平均每局只提前约5个动作，不能移动抢任务，也不能提前收获/入库 | 扩为依赖感知的准备流水线 |
| 多排班后果比较 | `regret_*` 比较覆盖数和路程；终局专用排班能模拟仓库波次 | 普通日不比较兑现收入；旧排班省工资却损失销售额 | 建立普通日的有限候选与因果后果评分 |

历史负结果不会删除：S3R/S3S/S3T 继续作为旧受限实现的证据，不能据局部正例宣称能力已完成。

## 3. 实现顺序

### S4A-1：逐步重协调薄层

- 采购队列与已成交结果是事实，不允许重启 `new_day()` 或重复下单。
- 已经完成的地块效果由真实状态消失；未完成工作重新从实际状态生成。
- 已携带的种子以外资源、shed 库存、仓库剩余容量必须进入重新分配。
- 同格同效果只允许唯一预留；被取消任务立即释放下游资源。
- 第一版只在“计划失效、出现未排硬任务、资源成交偏差、单位空闲且有可达任务”时触发重排；另设诊断模式每步检查。没有证据前不每步全量做昂贵搜索。

### S4A-2：共享任务原子 V2

- 由官方效果依赖生成可拆边：如存量动物的收获、收肥、喂养、CARE可分别分配。
- 不可拆边继续有序：建栏后才能放动物，放置后才能喂养；播种后才可浇水。
- 允许不同工人完成前后动作，但下一动作只在前置效果已由真实状态确认后进入任务池。

### S4A-3：准备流水线 V2

- 市场订单仍保持融资出售在购买之前，最多10条，按真实部分成交回写。
- 与本轮尚未成交资源无关的维护、收获、搬运、入库可以继续。
- 依赖未成交资源的 PLACE/FEED/FERTILIZE 不提前；成交后进入逐步重协调。

### S4A-4：人员编排后果比较

- 至少生成：现有贪心、共享任务优先、deadline优先、物流兑现优先四类合法排班。
- 评分顺序：确定可兑现收入 + 避免高价值硬 deadline 损失 - 工资 - 无法入库/出售的预期残余；路程仅作为成本项和近似平局决胜。
- 只使用当前可见状态和官方确定规则做有限视野估计，不查询真实未来随机事件。

## 4. 验收矩阵

每项先做机制测试和独立消融。组合只测试存在因果关系的链：

- A=`shared_task_atoms_v2`，B=`stepwise_recoordination`：共享任务只有在能滚动改派时才可能完整兑现。
- B×C=`preparation_pipeline_v2`：准备阶段执行后必须按真实状态接续。
- A×B×C×D：长链总效果。
- 对晋级组合再逐项关闭一个开关，验证贡献不是由隐藏覆盖造成。

机制硬门：完整719步、非法动作0、无法解释的无效果0、重复预留0、未计划 deadline miss 0、跨局污染0、市场账本闭合、官方1.32.7抽样逐步一致。

强度采用 C++ 最多16线程、双座位、实时对手完整局。对手固定为 G001、G003、Boatlee V29、Kaito V58、Lynn V5、EcoBot V7、Six-Day Fieldbook、Three-Day Router。平局不计胜。
