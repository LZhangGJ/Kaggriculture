# Frozen six-candidate comparison

Select the roster from evidence collected before these panels existed: Day9 expected selector, connected Day3 v1, connected Day3 v2, terminal suffix, v37 feed reserve, and original AFS R2. Evaluate all six on all three panels. Do not select candidates from new panel results or tune between panels. The v37 policy is a public-parent comparison; it does not demonstrate the team's Three-Layer architecture goal.

Each candidate receives 8,192 representative games, 4,096 stress games, and 8,192 holdout games. Every seed crosses all 16 pinned opponents and both candidate seats. The total is 122,880 primary games. Preflight games are separate verification evidence; they do not add weight to the primary scores.

Use strict wins divided by all scheduled games as the primary metric. A draw contributes zero wins. Record wins, draws, losses, valid, invalid and missing cases. Any invalid or missing case blocks a completed comparison. Preserve failures; a repair requires a documented cause and a new versioned run, without choosing the better outcome. The local per-game timeout is 180 seconds. These are local CPU results under the official 1.32.7 rules, not Kaggle-hosted sandbox or leaderboard results.

Freeze the roster, complete runtime bytes, runner, 16 opponents, panel manifests and this plan before preflight. Preflight uses the first representative seed against all 16 opponents in both seats, for each candidate. Compare the native simulator with the official interpreter at every observation in both seats. Compare actions and terminal cash between full-observation and sparse-observation execution. Where a native adapter runs a Python package faster, compare the unchanged package against that adapter on the same complete games. Keep all parity receipts. A repair to runner infrastructure requires a new hash and a fresh preflight before primary games.

Report representative, stress and holdout scores separately. For each panel, report the overall rate, each opponent and each candidate seat. Compare each candidate with AFS R2 and Day9 using paired differences. Use 4,000 seed-cluster bootstrap draws with key `kaggriculture-seed-contract-v1-bootstrap`. Draw one common bootstrap index matrix per panel using SHA256 of the key, a colon, and the panel name as the random seed. Keep all 32 opponent/seat games for a seed together. Use 95% percentile intervals. Use the same draws for candidates and their paired differences. Intervals are descriptive, without a multiple-testing adjustment; they do not authorize automatic promotion. Stress intervals describe only the selected stress panel.

Use these fixed reference-condition groups from the feature manifests: first PASS/PASS reference shop (eight groups); milk-minus-wool demand (negative, zero, positive); crop-minus-animal demand (negative, zero, positive); shop variety (at most four, at least five); maximum shop duplication (at most two, at least three). Also report each of the 26 selection coordinates as low, middle or high, using the representative feature sample's 25th and 75th percentiles with linear interpolation, before candidate results. Low includes the lower threshold; high includes the upper threshold except values already assigned low. Report distinct seed support; flag groups with fewer than 20 seeds. Apply the same thresholds to stress and holdout. The reference controller qualification stays attached to these labels.

Record actual public market inventory and prices before actions every four turns, at steps 0, 4, ..., 716 (180 samples per game). Record shop unlocks at their first available sample. For each product, retain price and inventory minima, maxima and sums, initial and last sampled inventory, and price-floor sample count (price equals 1). Report actual shop demand units from unlock times and the fixed town schedule, separately from center demand. These are actual action-dependent market descriptions. They are not hourly exposure measures or causal comparisons. For realized floor exposure, describe each product using zero, greater than zero but below one quarter, and at least one quarter of sampled turns. Do not pair candidates within these action-dependent groups or claim they faced the same economic path.

Run the full frozen six-candidate holdout comparison once, publish its seeds and results, and retire it from future fresh-confirmation use.
