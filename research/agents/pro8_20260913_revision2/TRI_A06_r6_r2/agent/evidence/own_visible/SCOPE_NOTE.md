# Evidence mapping

These files are exact copies from `TRI_A06_r6_r1_own_visible.zip`.
The original `MANIFEST.json` paths under `agent/` map to
`../../provenance/parent/` relative to this directory; every other manifest path
is relative to this directory. No opponent code, private state, complete
replay, previous larger ZIP, network retrieval, or new game is included.
The public official referee and its local CPU host are retained unchanged.
The local host is not the Kaggle timeout or schema validator.

All `FULL64_*` results refer to parent r1. They are not r2 validation scores.
