# 中文工作流

## 1. 由 Codex 建立目标并协调8个独立作者

Codex 负责整个迭代流程，包括准备规则与源码、向8个独立的 ChatGPT 6 Pro 会话派发任务、收集交付、运行本地比赛、分析结果以及安排下一轮修改。

每个 Pro 会话独立开发完整策略。可以给不同会话安排不同的研究重点，例如经济规划、作物组合、市场交易、资源分配和执行调度，同时采用统一的游戏规则、运行接口和评测方法。

## 2. 先建立平均20万现金的经济基线

每个作者先在没有主动对手的环境中，使用多个 seed 检验策略自身的经济能力，目标是平均每局终局现金达到20万。

作者可以使用动态规划和滚动规划，优化投资、生产、维护、收获与出售的完整过程。评价依据是实际完成比赛后的现金，而不是规划器预测的收益。没有达到基线的策略继续修改和测试，直到达标。

每个作者单轮任务不超过2小时。派发时应考虑其实际 CPU、内存与运行速度，为实现、验证和打包分配合理时间。交付应包含完整源码、可运行策略、构建说明和实际测试结果。

## 3. 让8个策略在本地互战，选出最强的两个

Codex 下载并核验8个策略，在统一环境下组织本地循环对战。相同轮次使用共同的 seed，并交换座位，减少地图和先后手对比较结果的影响。

根据完整互战结果选出最强的两个策略，重点比较总体胜率、对不同策略的表现和稳定性。本次选出的两条路线是 A08 和 A06。后续可以从这些路线继续产生多个版本，例如 A08 r11、A06 r6 和 A06 日历版 r12。

## 4. 让入选策略对战固定策略池

入选策略随后与我们的策略池对战，包括11个指定公开对手和原始 R2。

当前正式评测从公开的 representative 256 与 stress 128 种子集合中抽取64个未使用 seed。同一轮候选使用相同种子，每个候选与每个对手交换座位，因此每个候选完成：

64个 seed × 12个对手 × 2个座位＝1536局。

每次策略更新后更换 seed，避免围绕同一批对局反复优化。完整报告总体胜率、逐对手胜率、座位差异和平均终局现金。

实战验收以总体胜率严格超过85%为标准，不再设置20万现金硬门槛。 在1536局的面板上，这意味着至少1306场严格胜利，平局不算胜。

## 5. 由 Codex 分析关键败局并反馈给原作者

Codex 根据比赛结果筛选关键败局，包括大幅落败、接近获胜但失败，以及反复输给特定类型对手的比赛，同时保留险胜案例用于检查改动是否造成退化。

分析主要覆盖三个层面：

- 经济策略：投资是否合理，买卖时机是否合适，资金是否真正转化为收益。

- 滚动编排：生产、维护、收获、运输和出售是否形成可执行的计划。

- 底层执行：策略决定是否真正落实，是否存在动作失败、工人闲置、任务冲突或遗漏。

Codex 将必要的关键败局数据、分析结论和改进任务回传给生成该策略的 ChatGPT 6 Pro 会话。作者修改后交付新版本，Codex 再次核验，并使用新 seed 进行本地对战。

这个循环持续进行，直到候选策略在指定策略池中的总体胜率超过85%。每个正式版本保存源码、英文简介、评测设置与完整结果，并发布到 GitHub，使策略和成绩可以对应、复查与复现。

## 主要 Prompt

以下是可复用的任务模板，具体版本、文件和结果在派发时填写。

### 给 Codex 的 Goal：

```text
/goal
你是 Kaggriculture 策略迭代的中控。

协调8个独立的 ChatGPT 6 Pro 会话开发完整策略，先让每个策略在多个 seed 的无主动对手环境中达到平均每局20万终局现金。

下载并核验这些策略，在本地组织互战，选出最强的两个，再与我们的固定策略池对战。当前策略池为11个指定公开对手加原始 R2。

每次更新策略后使用新的 seed 进行评测。同轮候选使用共同的64个 seed，并交换座位，每个候选完成1536局。

分析比赛结果，将关键败局、证据和改进任务反馈给对应作者，持续优化经济策略、滚动编排和底层执行，直到总体实战胜率严格超过85%。实战阶段不再设置现金硬门槛。

根据作者环境的实际 CPU、内存和运行速度安排任务，每个作者单轮不超过2小时。保存并发布策略源码、英文简介、评测设置和完整结果。
```

```text
你负责独立开发一份完整的 Kaggriculture 策略。请阅读提供的规则、源码和运行环境，实际修改代码、运行测试并交付可下载的策略包。

目标是在多个 seed 的无主动对手环境中，达到平均每局20万终局现金。可以使用动态规划和滚动规划，优化投资、生产、维护、收获与出售，并确保计划能由底层执行器实际完成。

本轮研究重点为：<研究方向>。

先检查实际 CPU、内存和运行速度，再确定实现与测试规模。本轮从 <开始时间> 到 <截止时间>，总计不超过2小时。

交付完整源码、可运行策略、构建方法、英文简介，以及实际使用的 seed、逐局结果和耗时。平均现金必须来自真实完整比赛，不使用预测收益代替。
```
