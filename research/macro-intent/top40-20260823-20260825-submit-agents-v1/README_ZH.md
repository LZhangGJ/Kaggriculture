# 2026-08-23/25 Top40 宏观路线 Agent：G034 与 G096

本目录保存两个可以直接上传 Kaggle 的单文件 Agent。两者使用完全相同的33条候选后缀、鲁棒决策树、`[144, 216]` 在线判断序列和“最多切换一次”运行时；唯一差别是强制开局分别为 `G034` 与 `G096`。

训练数据为本地 2026-08-23 Top40 与 2026-08-25 Top40 Replay，先按 `episode + seat` 跨批去重，只保留官方 `kaggle-environments==1.32.7`。训练流程保持队友方案的宏观路线聚类、路线互打与经验 Nash、反事实后缀搜索、鲁棒浅决策树及单次切换结构。

## 文件

- `G034/main.py`：流程正式选择的主开局版本。
- `G096/main.py`：保持其余模型不变、只强制改为 G096 开局的备选版本。
- 两个 `PACKAGE_MANIFEST.json`：文件哈希、大小及官方验证摘要。
- `COMPARISON_METRICS.json`：下表的机器可读数据。
- `receipts/`：路线互打、hard7、序列搜索、最终 holdout 和官方1.32.7运行回执。

提交时只上传对应目录里的 `main.py`。

## 当前判断

- 若优先遵守完整训练流程和证据闭环，选择 `G034`：它是正式主开局，具有序列搜索与最终未见 seed holdout。
