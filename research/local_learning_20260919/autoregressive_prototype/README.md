# 自回归市场解码小样本实验

这个独立原型借鉴 Exact BC 分支的逐条动作生成方式，复用当前冻结编码器及已有训练数据。它不改动正在验收的候选、不运行对战，也不注册或使用新对战 seed。

`prototype.py` 输入当前观测的 11 个市场 token（各 128 维），用 128 维 GRU 保存本回合已生成的命令和数量前缀，依次预测 31 类命令与 EOS、以及 None/0..1000 数量词表中的整数。最多生成 10 条请求，EOS 后输出 PAD。需要数量的命令屏蔽 None。市场完整组合词表不参与预测。GRU 状态每回合重新初始化；这次没有加入跨回合记忆或工人阶段结算特征。

训练只更新独立的 722,697 参数解码头。复用当前辅助命令头、市场数量头和相应嵌入作为初始化；基础模型的所有张量保持不变。损失为每条样本有效命令的平均交叉熵加所需数量的平均交叉熵，包含 EOS，忽略 EOS 后位置。

运行检查：

```powershell
$env:PYTHONUTF8='1'
& 'F:\Kaggriculture\experiments\segmented_bc_20260915\.venv\Scripts\python.exe' -B '.\autoregressive_market75_20260919\prototype.py'
```

脚本读取 `market_quantity75_20260918` 的已冻结权重及训练数组，启用已有 CPU 限制器。检查小样本学习、自由解码、前缀因果性、EOS 后损失屏蔽、空序列与最大长度、codec 往返、基础权重和单位动作不变，并测量热启动单线程推理时间。结果保存于 `PROTOTYPE_CHECK.json`，拟合权重不保存或晋升。

这些样本都是已用于训练的数据。27/27 命中只能作为实现与可学习性检查；不能代表未见组合泛化、完整策略胜率或正式环境的超时保证。后续正式实验需要全量训练、独立验证、保持历史样本覆盖，以及全部使用不同 seed 的完整对手池验收。
