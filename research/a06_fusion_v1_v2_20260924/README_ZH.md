# A06 融合 V1 / V2

V1 入口为 `v1/main.py`，V2 入口为 `v2/main.py`。每版包含 67 个冻结源码、配置、运行库及原始来源文件，逐字节匹配实际测试版本。V1 仍是保留基线，V2 是未晋级的比较版本。

## 两版改了什么

共同部分基于原 Cashflow 动态 Agent：保留其产出回款估值、对手公开成熟产出驱动的销售逻辑与原生规划/执行器；加入 Liquidity 开局小麦买 10 / 卖 10 的交易意图及现金、库存、订单数量约束；关闭日内新增项目准入与采购，保留日初经济规划和既有任务执行；雇工上限设为 12。

V1 的 `animal_bias=1.0`；V2 将其改为 `0.6`，降低新动物候选的评分。这不是把动物数量固定为 60%。C++ 源码和原生运行库相同。两版均不使用 ML/RL，也不根据对手名字、测试种子或对手私有状态选择策略。

## 结果

| 对手 | V1 胜率 | V2 胜率 |
|---|---|---|
| 队友 V306 | 119/200，59.5% | 123/200，61.5% |
| 队友 V463 | 110/200，55.0% | 123/200，61.5% |

100 个相同环境种子、双座位；保留队友原包采样行为，另行记录独立采样随机种子，并在 V1/V2 间配对。800 盘均完整结束，17 个模型接管日全部执行，没有异常、平局或模型回退。8 局烟测及 6 局串行复跑的双方动作哈希与终局现金 14/14 一致；这些重复局不计入 800 盘。

之前独立验收中，V1 内战 95.62%、外战 86.10%；V2 内战 95.54%、外战 83.20%。两者不是同一批种子。另一次严格同种子外战比较为 V1 86.30%、V2 83.20%。因此双面板 90% 目标未达成，V2 没有替换 V1。完整置信区间及逐对手结果见 `evidence/`。

最新对 V463 的串行抽查，V1/V2 单步最高 1.108/1.214 秒；对 V306 的 V2 抽查最高 1.557 秒。本地对战使用官方 1.32.7 规则，但没有按 Kaggle 沙箱的超时机制判负，不能将上述胜率视为平台超时验收。

## 使用与复现

`main.py` 中的 `agent(observation, configuration)` 是入口。把对应版本目录作为完整运行包使用，不要只复制 main.py；需要其配置、Python 辅助文件和 `policy/a06.so`。附带运行库适用于兼容 Linux x86-64 / WSL，需要 GLIBC_2.32、GLIBCXX_3.4.31 或兼容运行库；不是 Windows DLL。可用对应目录的 `build.py` 重编译，换编译环境后需重新验证。

在本目录下运行：

```text
python verify_package.py
python reproduce_one.py --candidate-version v1 --pool ../a06_dynamic_variants_public10_20260924 --opponent internal/r14_cashflow --seat 0
python reproduce_teammate.py --candidate-version v2 --opponent student_v463 --opponent-root /path/to/extracted/student-v463 --seat 0
```

队友原包和权重不重复上传；从各自的完整提交 tar.gz 解压后提供 `--opponent-root`。V306 原包 SHA-256 为 `908235e386d73252505a7b3879079d07e835d1c0ec78533f13a69ea1f2c2bdaa`；V463 为 `7a8fcabeb04096e330bacc3e6d6acb42a9cb3b93567c0bfb1b4cb1de05092445`。脚本会核验对手文件哈希以及我方/裁判哈希，并将现金和双方完整动作哈希与已保存逐局数据比较。

队友对战复现环境是 Python 3.12、CPU PyTorch 2.9.1、NumPy 2.2.6，每进程单线程。V1/V2 自身推理不依赖 PyTorch，PyTorch 用于运行队友模型。`evidence/teammate/` 保留测试协议、逐局压缩回执及原始实验脚本；原始脚本含旧工作区路径，便携复现请使用根目录的脚本。

历史报告中的 `agent_v1/`、`agent/` 分别对应本目录 `v1/`、`v2/`；版本目录里的父版 README、历史报告不是当前融合成绩。当前文件完整性以根目录 `MANIFEST.json` 为准。
