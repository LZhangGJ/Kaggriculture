# A06 R14 CASHFLOW

纯规则实验版，基于 A06 R12 r4 → R13 PUBLIC。

最终配置仅启用 `delivery_calendar=0.5`：单个田间项目预测的正向产出，按50%当日、50%次日分配；成本和劳动保持原日；最终日不继续顺延。已有仓库和背包货物在组合中单独计入，不应用此函数。此比例是启发式预期，不是已知的未来实际回款时间。

原版产业规划、执行器、R13公开成熟商品出售规则保留。`r14_fert_floor=0`，不启用本轮失败的肥料收集删减。无模型权重、无ML/RL；负数scenario会被拒绝。

## 当前结果

附件冻结10对手，8种子交换座位，每对手16盘：87/160胜，54.375%。R13为82/160。逐对手80%/90%均未达标。不得作为已达标版本。新种子复核R13为6/16、R14为4/16，因此未晋级为稳健替代版。完整数据见包内或完整实验包的CSV、中文报告。

## 运行

`main.py` 提供 `agent(observation, configuration)`，本地独立对局使用 `create_agent()`，结束后调用 `close()`。

原生库已提供，Linux x86-64。该动态构建需要GLIBC_2.32、GLIBCXX_3.4.31及兼容C++运行库。没有在Kaggle平台沙盒认证。源码重编译：

```bash
python build.py --cxx g++-14 --unit
```

不要删除 `animal_path` 的 `noipa` 编译隔离，也不要把不同版本Settings的Python编码器与原生库混用。正式成绩由冻结官方Python规则结算；原生库内模拟仅用于决策预测。

`policy/a06.BUILD.json`记录实际编译输入；`RELEASE_MANIFEST.json`记录运行时配置和交付文件哈希。配置在运行时读取，不在原生库中固化。

本地并行测试最大单次调用约1.278秒，超过冻结actTimeout的1秒基准；尚未验证平台额外时间额度及总超时扣减。
